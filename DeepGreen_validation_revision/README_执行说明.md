# DeepGreen 人工检验执行说明

## 已生成文件

- `LayerA_人工标注指南.md`：Layer A 语境化人工标注规则。
- `LayerB_人工标注指南.md`：Layer B 实质性/象征性披露标注规则。
- `LayerA_人工标注样本.csv`：共 1,000 条，分 10 轮，每轮 100 条；每轮按现有模型标签抽取 50 条正类和 50 条负类。目标词已在真实原句中以 `##目标词##` 标记。
- `LayerB_人工标注样本.csv`：共 500 条；按现有原始模型标签抽取 250 条正类和 250 条负类。
- `prepare_validation.py`：可复现抽样，并在人工标注完成后计算检验指标。

## 人工标注步骤

1. 标注者先阅读相应的 Markdown 指南。
2. 在两个 CSV 的 `人工标签` 列填入 `0` 或 `1`。
3. 在 `简短判断依据` 列填写一句简短理由。
4. 不修改 `sample_id`、目标词/关键词、完整原句、模型标签和模型 confidence。
5. 完成全部人工标签后运行：

```powershell
python "prepare_validation.py"
```

脚本会验证所有人工标签，并生成：

- `LayerA_检验结果.json`：10 轮结果及 pooled 结果；
- `LayerB_检验结果.json`：500 条样本的 pooled 结果。

每份结果均包含：

- 混淆矩阵的 `TP`、`TN`、`FP`、`FN`；
- `Accuracy`；
- `Precision`；
- `Recall`；
- `F1`；
- `MCC`。

## 当前状态

抽样、语境匹配、标注表和计算程序已经完成。由于人工标签必须由实际人工标注者填写，目前结果文件要在人工标注完成后才能生成；不能用模型标签代替人工标签，否则不构成人工检验。
