# `company_pair_x_variables.parquet`

同年度、同行业的无序公司对。一行是一对公司，只保留证券代码升序的 `i < j`。

## 规模

| 项目 | 数量 |
| --- | ---: |
| 行（公司对） | 2,051,610 |
| 列 | 21 |
| 年度 | 2021–2024 |
| 公司 | 4,949 |
| 行业代码 | 47 |

| 年度 | 配对数 |
| --- | ---: |
| 2021 | 396,621 |
| 2022 | 492,755 |
| 2023 | 578,249 |
| 2024 | 583,985 |

## 列

标识列在全部行上有值。后面的变量只在适用样本上有值，不适用的行留空。

| 列 | 含义 | 非空行 |
| --- | --- | ---: |
| `时间` | 年度 | 2,051,610 |
| `ExpertiseIndustryCode` | 行业代码。制造业为证监会两位代码，其他行业为一位门类代码 | 2,051,610 |
| `证券代码_i` | 配对中代码较小的公司 | 2,051,610 |
| `证券代码_j` | 配对中代码较大的公司 | 2,051,610 |
| `CleanInstitutionID_i` | i 的境内主审所代码 | 2,051,610 |
| `CleanInstitutionID_j` | j 的境内主审所代码 | 2,051,610 |
| `SameAF` | 两家当年是否同一家事务所。1 同所，0 不同所 | 2,051,610 |
| `ChgCo` | 双方上一年都有记录时：上年不同所、本年同所为 1，否则为 0 | 1,420,627 |
| `ChgCo_FromDiff` | 只在上年不同所的公司对中：本年变为同所为 1，仍不同所为 0 | 1,315,447 |
| `BreakCo` | 双方上一年都有记录时：上年同所、本年不同所为 1，否则为 0 | 1,420,627 |
| `SameBig4` | 只在当年同所时：共同事务所是四大为 1，否则为 0 | 153,692 |
| `SameBig10` | 只在当年同所时：共同事务所是国内十大为 1，否则为 0 | 153,692 |
| `ChgBig4` | 当年同所且双方上年都有记录：由同一家非四大改为同一家四大为 1，否则为 0 | 105,644 |
| `ChgBig10` | 当年同所且双方上年都有记录：由同一家非十大改为同一家十大为 1，否则为 0 | 105,644 |
| `SharedCPACount` | 当年同所且双方签字师都非空：共享签字师人数 | 153,673 |
| `AnySharedAud` | 同上样本：至少共享一人为 1，否则为 0 | 153,673 |
| `SameAud` | 同上样本：签字师团队完全相同为 1，否则为 0 | 153,673 |
| `SimRt` | 共享人数 / 双方人数之和。团队完全相同为 0.5 | 153,673 |
| `SimJaccard` | 共享人数 / 并集人数。团队完全相同为 1 | 153,673 |
| `ChgAud` | 当年同所且双方当年、上年签字师都非空：团队由不完全相同变为完全相同为 1 | 105,644 |
| `ChgRt` | 同上样本：本年 `SimRt` 高于上一年为 1。上年不同所时，上年重合度记为 0 | 105,644 |

同所公司对共 153,692 个。其中 19 对因签字师为空，没有 `SharedCPACount` 至 `SimJaccard`。2021 年没有上一年，`ChgCo`、`BreakCo` 以及各变动变量在该年为空。
