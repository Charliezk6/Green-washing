# SPEC（审计收费份额第一）替换自变量：结果汇总

本目录把核心解释变量从 `IMS` / `IMS_D`（营业收入份额 ≥ 0.20）换成 `SPEC`，其余设定（因变量、14 个控制变量、1%/99% 缩尾、年度与行业固定效应、公司聚类、样本筛选、匹配参数）均与原分析一致。原结果只读取、未修改。

## 1. 变量定义

事务所 \(a\) 在行业 \(k\)、年度 \(t\) 的审计收费市场份额：

\[
FeeShare_{a,k,t}=\frac{\sum_{i\in(a,k,t)} Fee_{i,t}}{\sum_{i\in(k,t)} Fee_{i,t}}
\]

行业专长哑变量：

\[
SPEC_{i,t}=1\left\{FeeShare_{a(i),k(i),t}=\max_{b} FeeShare_{b,k(i),t}\right\}
\]

- 市场范围：全 A 股 2021–2024（`X_reproduction/data/input/full_a_share_audit_market_2021_2024.csv`），审计收费取 `appendix/**/AIQ_FinAuditOpinY.csv` 中 `EndDate` 为 12-31 的 `TotalAuditFee`，仅 `Fee > 0` 的观测进入份额计算。
- 行业口径与 `IMS` 相同：制造业取 C 类二级代码，其他行业取首字母，剔除 O 类和缺失行业代码。
- 客户的主审事务所按“证券代码-年度”取自全市场文件。共同样本中有 103 行与面板里的 `InstitutionID` 不一致，这样取可以让 15,381 条全部匹配。
- 并列第一时，并列的事务所都记为 1（188 个行业-年度中只有 1 个出现并列）。
- 构造校验（`00_build_spec/outputs/build_checks.json`）：每个行业-年度都有份额第一；份额之和为 1；与 FirmFE 中现有的 `IMS_fee` 相比，4,127 个共同单元格的份额最大差为 5.6e-17，份额第一的判定 100% 一致。
- LOO 版本：\(SPEC\_LOO_{i,t}=1\{A_{a,k,t}-Fee_i>0\ \text{且}\ A_{a,k,t}-Fee_i\ge\max_{b\ne a}A_{b,k,t}\}\)，其中 \(A\) 为事务所-行业-年度的收费合计。

## 4. 稳健性检验

### 4.1 换所分析（`03_auditor_change`）

核验后的换所事件有 1,337 个。其中换入 SPEC 事务所的有 149 个，原口径下换入 IMS_D 事务所的有 98 个；从非专长升级为专长的有 136 个（原口径 69 个）。

| 检验 | SPEC | 原 IMS_D |
|---|---|---|
| 选择方程：L_GW 预测换入专长（W1，Logit） | 0.093 (0.065)，p = 0.151 | 0.099 (0.090)，p = 0.274 |
| 选择方程：L_GW（W1，LPM） | 0.008 (0.006)，p = 0.193 | 0.002 (0.005)，p = 0.615 |
| 上期是否专长 L_SPEC / L_IMS_D（W1，LPM） | -0.026，p = 0.402 | 0.191，p = 0.001 |
| 事前趋势（t-2 到 t-1 漂绿变化，SMD） | -0.047 | -0.018 |
| 换所后漂绿变化 ΔGW 对 SwitchInExpert | -0.008 (0.099)，p = 0.933 | -0.319** (0.137)，p = 0.020 |

两种口径下，上期漂绿都不能预测是否换入专长事务所，所以不存在“漂绿公司主动选择专长事务所”的证据。但 SPEC 口径下，换入专长事务所之后漂绿**没有**下降，原 IMS_D 口径下则显著下降。

| 变量 | 系数 | 标准误 | p 值 | N |
|---|---:|---:|---:|---:|
| SPEC（同样本） | -0.0957 | 0.0506 | 0.058 | 15,381 |

转移情况：1,966 个 SPEC=1 观测中，剔除自身收费后仍为份额第一的有 1,788 个（SPEC_BOTH）；失去第一的有 178 个（SPEC_LOST），其中 14 个是因为该客户是事务所在该行业-年度的唯一客户，164 个是被对手事务所反超。SPEC=0 的观测不可能因剔除自身收费而变成份额第一。

| 拆分回归（参照组：SPEC=0） | 系数 | 标准误 | p 值 |
|---|---:|---:|---:|
| SPEC_BOTH | -0.0904 | 0.0522 | 0.084 |
| SPEC_LOST | -0.1491 | 0.1502 | 0.321 |

按漂绿的两个组成部分拆分（同一规格）：

| 因变量 | SPEC | SPEC_LOO |
|---|---|---|
| 披露 GI_z | 0.008 (0.037)，p = 0.832 | 0.012 (0.039)，p = 0.759 |
| 环境表现 ESGE_z | 0.104*** (0.033)，p = 0.002 | 0.100*** (0.034)，p = 0.003 |

原 IMS 的 LOO 检验之所以不显著，是因为连续营收份额的一部分来自公司自身的营收（机械相关）。SPEC 基本不受这个问题影响：91% 的 SPEC=1 观测在剔除自身后仍是份额第一，SPEC_LOO 的系数与 SPEC 几乎相同，并在 10% 水平显著。拆分结果还显示，SPEC 降低漂绿主要是因为其客户的环境表现得分更高，而不是披露更少。

## 5. 总体结论

| 检验 | SPEC 是否支持“专长降低漂绿” | 原 IMS_D |
|---|---|---|
| 基准回归（全部控制） | 支持，10% 水平 | 支持，10% 水平 |
| 聚类（7 种）与 wild bootstrap | 支持，全部至少 10% 水平，更稳健 | 多数不显著 |
| LOO | 支持，10% 水平，明显优于原口径 | 不显著 |
| PSM（PS-Full，M2） | 支持，10% 水平 | 支持，5% 水平 |
| EB（B1） | 方向为负，不显著 | 支持，5% 到 10% 水平 |
| 换所后漂绿变化 | 不支持（接近 0） | 支持，5% 水平 |
| 企业固定效应 | 不支持（系数为正，接近 0） | 不显著，方向为负 |

SPEC 的优势在于推断的稳健性：按处理分配结构聚类、wild bootstrap、剔除自身份额后，结果都比 IMS_D 更站得住。它的弱点在于识别：EB、换所前后对比和企业固定效应都依赖公司内部或处理前后的比较，在这些检验里 SPEC 的效应基本消失，Mundlak 分解也表明效应主要来自横截面差异。

## 6. 标注为“不适用”的部分

这些分析只针对连续的 `IMS`，SPEC 只有一个二元指标，所以没有对应的版本：

- Cluster：“事务所-行业-年度单元格内 IMS 是否唯一”的诊断。
- EB：B2（连续 IMS 加全部滞后控制），以及与 GPS 连续处理结果的对比。
- LOO 诊断：OWN / SHARE / CELL_SHARE 分解、FWL 协方差分解、系数差检验、binscatter，以及“剔除单客户单元格 / 剔除高 SHARE 样本”的子样本回归。
- FirmFE：测量误差 EIV 与 IV 纠偏（`measurement_error_correction.py`）、替代度量汇总表（`run_alt_measures_firm_fe.py`）、合伙人层 PIMS 流水线（`partner/`）和换签字人 DiD。
