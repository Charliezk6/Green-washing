# 《Decoding China's Industrial Policies》中的 LLM 文本识别检验与稳健性设计

## 1. 文献信息与研究任务

- **作者**：Hanming Fang、Ming Li、Guangli Lu
- **题目**：*Decoding China's Industrial Policies*
- **版本**：NBER Working Paper No. 33814，初稿 2025 年 5 月，2026 年 7 月修订版
- **原文链接**：<https://www.nber.org/papers/w33814>
- **数据规模**：2000—2022 年中国中央、省和城市等层级政府发布的约 328 万份政策文件
- **LLM 主要任务**：
  1. 判断文件是否属于产业政策；
  2. 判断政策语调，包括支持性、监管性和抑制性；
  3. 提取政策直接针对的行业，并映射至三位数和四位数标准行业代码；
  4. 将政策工具归入 20 个类别；
  5. 提取政策目标、适用条件和组织实施安排；
  6. 对政策具体性和政策强度进行评分。

这篇论文的核心方法特点不是简单地用一个 prompt 对全部文本做一次分类，而是建立了一个以**防幻觉、多轮审查、人工验证和外部效度**为核心的 LLM 测量流程。

---

## 2. 作者认为 LLM 文本识别面临的主要问题

论文特别强调，长篇、复杂且异质的政策文件会带来以下风险：

1. **幻觉**：模型生成原文中不存在的行业、政策措施或判断依据；
2. **长文本理解困难**：关键信息分散在文件不同位置；
3. **复杂 prompt 性能下降**：即使模型支持长上下文，一次询问过多问题也会降低表现；
4. **概念边界模糊**：一般经济政策、短期稳定政策和产业政策之间并不天然清晰；
5. **提及不等于政策对象**：文件可能提到很多行业，但只有部分行业是直接政策目标；
6. **过度精确分类**：文本只支持宽泛行业时，强行映射至四位数行业会产生虚假精确性；
7. **类别不平衡**：产业政策文档仅占全部文件约 18.16%，总体 Accuracy 容易掩盖正类识别不足；
8. **人工标签也不完全一致**：人工标注者对主观复杂构念同样存在分歧；
9. **测量结果是否具有现实意义**：即使 LLM 与人工一致，也需要证明构造出的政策变量能够预测真实经济行为。

作者因此把问题分成两个层面：

- **过程层面**：如何通过 prompt、任务拆分和多轮复核降低幻觉和误分类；
- **结果层面**：如何通过人工 gold set、传统模型基准和外部经济结果验证 LLM 标签。

## 3. 防止幻觉和提高分类可靠性的流程设计

## 3.1 提供严格定义、标准和反例

作者首先给出产业政策的窄口径定义。一份文件只有同时满足以下四项标准才被判为产业政策：

1. 发布者必须是政府实体；
2. 必须包含具体政府行动，而非一般性表态或工作总结；
3. 必须明确偏向或限制某些特定行业；
4. 必须服务于长期产业结构转型，而不是疫情或周期性衰退等短期稳定目标。

除正面定义外，作者还反复向 prompt 加入**容易混淆的反例**。这些反例并非一次性凭主观设定，而是通过以下方式形成：

1. 对第一轮结果随机抽取 10,000 份文件；
2. 让能力更强的 LLM 审查并总结常见错误；
3. 人工专家检查 LLM 总结；
4. 将确认后的错误类型整理成 examples 和 counterexamples；
5. 加入下一轮 prompt；
6. 若前两轮仍有明显分歧，则继续迭代，直至不再发现新的常见错误类型。

这种方法相当于把错误分析转化为 coding manual 的持续修订，但最终规则仍由人工专家把关。

## 3.2 把复杂任务拆成逐步子问题

作者没有直接只问“这是不是产业政策”，而是在判断之前要求模型回答 11 个细化问题，包括：

- 政策发布主体是谁；
- 是否存在明确政策行动；
- 是否针对具体行业；
- 政策目标是什么；
- 是否属于长期结构转型；
- 判断依据是什么。

任务拆解使模型必须逐项检查构念条件，减少凭标题、关键词或整体印象直接判断。

## 3.3 要求输出原文证据、理由和置信度

每个主要问题的输出均包含：

- 原文中的相关段落或句子；
- 简洁的判断理由；
- 0—100 的 confidence score；
- 最终标签或提取结果。

这里，原文证据具有两项功能：

1. 提升可解释性，便于人工和其他模型审查；
2. 允许程序在查询后核实引用片段是否真的存在于原文，从而直接识别一部分幻觉。

需要注意，论文把 confidence score 用于多轮结果合成和阈值判断，但没有将其等同于经过统计校准的概率。

## 3.4 强调只依据提供的文本判断

作者在 prompt 中采用以下约束：

- temperature 设置为 0，以增强一致性；
- 指定模型扮演中国产业政策专家；
- 强调只能依据当前政策文本回答；
- 允许回答“不知道”；
- 要求采用保守判断，降低假阳性；
- 要求不同子问题的回答逻辑一致；
- 使用清晰、结构化的输出格式；
- 重复强调关键定义和边界。

这些约束主要用于提高可重复性和减少模型在证据不足时的过度推断。

## 3.5 分离“文本证据提取”和“类别判断”

这是论文最重要的防幻觉设计之一。

作者不让模型直接从完整长文一步生成全部结构化标签，而是分成：

1. 从政策全文中提取与目标行业或政策工具有关的原文；
2. 对提取内容进行补充、删除幻觉并区分主要目标与简单提及；
3. 再将经过整理的原文证据映射到行业代码或政策工具类别；
4. 由其他模型复核映射结果。

这样做可减少模型因为看到类别列表而在原文证据不足时强行匹配，也能保留完整审计链条。

## 3.6 将大任务分成两个主要查询阶段

尽管 Gemini-1.5 支持很长上下文，作者仍发现过长、过于复杂的问题会降低表现，因此采用两个主要阶段：

- **第一阶段**：对全部政策文件执行产业政策识别、发布者、目标行业、政策语调、政策工具、政策强度、适用条件等基础任务；
- **第二阶段**：只对初步判为产业政策的子样本重复部分核心问题，并进一步提取实施期限、组织安排、政治激励、地方适应和政策引用等信息。

这种设计避免一次调用同时承担过多任务，同时通过重复提问对关键变量形成内部复核。

## 4. 多模型、多轮迭代和结果合成

## 4.1 产业政策二分类的三轮判断

论文对“是否为产业政策”执行三轮判断：

### 第一轮

- 模型：主要使用 `Gemini-1.5-flash-001`；
- 输入：政策全文、详细定义和逐步问题；
- 输出：判断结果、原文证据、理由和置信度 \(S_1\)。

### 第二轮

- 模型：能力更强但成本更高的 `Gemini-1.5-pro-exp-0827`；
- 先在第一轮判为产业政策的 10,000 份随机文档上总结错误；
- 人工复核并形成反例；
- 为控制成本，这一轮正式判断主要使用政策标题；
- 输出置信度 \(S_2\)。

### 第三轮

- 模型：`Gemini-2.5-flash`；
- 输入：全部政策全文，加上前两轮总结并经人工复核的正例和反例；
- 输出置信度 \(S_3\)。

### 最终判定规则

文件满足以下任一条件时判为产业政策：

\[
S_3 \ge 90,
\]

或任意两轮置信度之和达到 180：

\[
S_1+S_2\ge180,
\quad
S_1+S_3\ge180,
\quad
S_2+S_3\ge180.
\]

作者给予第三轮较高权重，因为它使用较强模型处理完整政策全文。阈值不是理论推导值，而是基于随机样本的多次实验确定，且作者有意采用较严格阈值。

## 4.2 目标行业识别的多阶段流程

目标行业识别不是简单的全文到行业代码映射，而是：

1. 两轮从完整政策文本中提取行业相关原文；
2. 让额外 LLM 对两轮证据和完整文本进行复核；
3. 补充遗漏证据，删除幻觉；
4. 区分直接主要目标和仅被提及的行业；
5. 将整理后的目标行业证据交给较强模型；
6. 分别映射到三位数和四位数行业代码；
7. 检查四位数代码是否隶属于对应三位数代码；
8. 使用 `Gemini-1.5-flash` 和 `GPT-4o-mini` 再做两轮映射复核；
9. 按多模型是否同意及 reviewer confidence score 合并最终结果。

分层映射同时解决两个问题：

- 三位数与四位数之间形成内部一致性检验；
- 当文本证据只支持宽泛行业时，允许停留在三位数，避免虚假精确性。

## 4.3 政策工具识别的四轮 refinement

20 类政策工具的处理流程为：

1. 从原文提取政策工具相关段落；
2. 按明确类别定义进行初次映射，并允许一段文字映射多个工具，以减少假阴性；
3. 基于 10,000 份随机样本总结常见错误，由人工整理反例；
4. 在第二轮中加入更详细定义和反例；
5. 第三轮让模型结合原文证据和前两轮结果进行 self-critique；
6. 第四轮交给相对正交的 `GPT-4o-mini` 再审查；
7. 合并四轮结果形成最终工具分类。

这实际上组合了：多轮证据提取、错误驱动的 prompt 修订、模型自我批评和跨模型审查。

## 5. 人工内部验证

## 5.1 抽样和人工标注设计

作者从全部政策文件中**随机抽取 2,000 份文件**，招聘 20 名研究助理标注：

- 每位 RA 标注 300 份文件；
- 每份文件由 3 名 RA 独立标注；
- 研究助理接受 3 次培训；
- 使用详细 coding manual；
- 人工使用与 LLM 相同的产业政策四项定义。

这一设计的重要性在于，验证样本是从完整语料库随机抽取，而不是只选模型认为困难或只选正类样本，因此可估计总体性能。

## 5.2 人工标签本身存在分歧

在 19.25% 的文档中，三名 RA 未能完全一致。这说明“产业政策”本身是带有判断性的复杂构念，人工标签并非天然无误。

作者采用两个 gold-standard 口径：

1. **多数票口径**：至少 2 名 RA 判为产业政策即记为正类；
2. **全体一致口径**：只分析 3 名 RA 完全一致的样本。

这种双口径处理可以观察模型表现是否随人工标签确定性提高而改善。

## 5.3 混淆矩阵和分类指标

### 全部 2,000 份样本，以 RA 多数票为准

混淆矩阵为：

| | 人工正类 | 人工负类 |
|---|---:|---:|
| LLM 正类 | 287 | 69 |
| LLM 负类 | 79 | 1,565 |

对应指标：

- Accuracy：92.6%；
- Precision：80.6%；
- Recall：78.4%；
- F1：79.5%。

### 只保留三名 RA 完全一致的样本

混淆矩阵为：

| | 人工正类 | 人工负类 |
|---|---:|---:|
| LLM 正类 | 186 | 28 |
| LLM 负类 | 19 | 1,382 |

对应指标：

- Accuracy：97.1%；
- Precision：87.2%；
- Recall：90.7%；
- F1：89.0%。

结果显示，人工意见越明确，LLM 与人工的一致性越高。这说明模型错误中有一部分集中在构念边界模糊的文档，而不是随机分布。

## 5.4 该人工验证设计的优点

- 随机样本来自完整语料库；
- 每份文档有三名独立标注者；
- 有正式培训和 coding manual；
- 不仅报告 Accuracy，还报告 Precision、Recall 和 F1；
- 提供混淆矩阵；
- 同时报告多数票和全体一致两个 gold-standard 口径；
- 主动披露人工不一致比例。

## 5.5 仍可加强之处

论文没有在正文中报告：

- Fleiss’ \(\kappa\) 或 Krippendorff’s \(\alpha\)；
- 各指标的置信区间；
- LLM 在不同年份、政府层级、文档长度和类别上的分组表现；
- 政策语调、目标行业和 20 类政策工具各自相对于人工标签的完整指标；
- confidence score 的校准曲线；
- 最终多轮阈值是否在独立验证集上预先冻结。

因此，其内部验证对核心“是否产业政策”二分类很强，但对所有下游提取变量的人工验证披露相对有限。

## 6. 与传统文本分类方法的基准比较

作者使用相同的 2,000 份人工标注文件，将其划分为：

- 训练集 1,400 份，即 70%；
- 验证集 300 份，即 15%；
- 测试集 300 份，即 15%。

采用分层抽样维持正负类比例，并使用 3 个随机种子重复三次后取平均。

比较模型包括：

- L1 Logistic Regression；
- L2 Logistic Regression；
- Elastic Net Logistic Regression；
- Random Forest；
- 仅优化分类层的 Chinese BERT；
- 全网络 fine-tuning 的 Chinese BERT；
- 作者的多轮 LLM 流程。

### 主要比较结果

| 方法 | Precision | Recall | F1 | Accuracy |
|---|---:|---:|---:|---:|
| Logistic-L1 | 0.4898 | 0.7394 | 0.5841 | 0.8033 |
| Logistic-L2 | 0.7466 | 0.5273 | 0.6039 | 0.8744 |
| Logistic-Elastic Net | 0.5128 | 0.7273 | 0.5983 | 0.8211 |
| Random Forest | 0.5765 | 0.5818 | 0.5684 | 0.8378 |
| BERT（仅分类层） | 0.5423 | 0.5515 | 0.5384 | 0.8244 |
| BERT（全网络） | 0.6432 | 0.7030 | 0.6708 | 0.8733 |
| LLM | 0.8066 | 0.7576 | 0.7813 | 0.9222 |

论文据此认为，LLM 在所有报告指标上优于经过优化的传统方法，尤其是在提高 Recall 的同时没有明显牺牲 Precision。

### 基准模型的严谨处理

- Chinese BERT 对超过 512 tokens 的文件采用重叠 sliding window；
- 使用 class balancing 或 minority oversampling；
- 在训练集进行超参数搜索；
- 在验证集选择最大化 F1 的分类阈值；
- 测试集只用于最终评价；
- 各模型均重复三次以降低 BERT 训练不稳定性的影响。

需要注意：LLM 本身不是在这 1,400 份训练集上训练的，因此这里比较的是最终任务表现，而不是完全相同的数据训练制度。但这种比较仍能说明，传统小样本监督学习在长篇、复杂政策文本上的表现不如多轮 LLM 流程。

## 7. 外部效度和经济含义验证

作者没有把“与人工一致”视为验证的终点，而是进一步考察 LLM 构造的政策变量是否预测真实企业行为。论文明确说明，这些分析是**预测性或内容效度检验，不是因果识别**。

## 7.1 企业获得政策资源的预测检验

作者将城市—行业—年份的政策暴露区分为：

- 支持性产业政策；
- 监管性或抑制性产业政策。

然后使用事件研究形式，考察政策前后企业：

- 获得的补贴；
- 税收减免率；
- 获得长期债务的概率。

结果显示：

- 支持性政策预测更高补贴、更多税收减免和更高长期融资可得性；
- 监管性或抑制性政策的关系较弱或方向相反。

这与文本标签所表达的政策语调一致。

## 7.2 企业进入的预测检验

作者在城市—行业—年份层面检验：

- 支持性政策发布后，新注册资本和企业进入增加；
- 监管性或抑制性政策对应较低的后续进入。

使用事件研究中的 leads 和 lags，可以观察政策效果的时间顺序，并检查政策前是否已经出现明显变化。

## 7.3 与五年规划传统指标进行增量效度比较

为排除 LLM 指标只是重复传统五年规划信息，作者加入高度饱和的：

- 城市 × 行业 × 五年规划周期固定效应；
- 年份固定效应。

即使吸收五年规划的行业指定和规划周期内稳定的发展重点，LLM 政策指标仍能显著预测企业进入。

这提供了**增量效度**：LLM 从大量地方政策文本中提取了五年规划指标无法覆盖的高频和地方层面变化。

## 8. 论文采用的稳健性逻辑汇总

| 风险 | 论文的解决办法 | 验证类型 |
|---|---|---|
| 概念定义不清 | 四项严格定义、详细 coding rules 和反例 | 内容效度 |
| 长文本和复杂任务 | 分阶段查询、拆成 11 个子问题 | 流程稳健性 |
| 模型幻觉 | 要求原文摘录并核验摘录是否存在 | 可审计性/事实核验 |
| 直接分类造成过度推断 | 先提取证据，再做分类或代码映射 | 结构化防幻觉 |
| 单模型偶然错误 | Gemini 多版本与 GPT-4o-mini 多轮审查 | 跨模型稳健性 |
| 第一轮系统性错误 | 10,000 份样本错误总结、人工审查、反例迭代 | 错误驱动 refinement |
| 输出随机性 | temperature = 0 | 重测一致性控制 |
| 证据不足仍强行回答 | 允许“不知道”、保守判断 | 假阳性控制 |
| 提及行业被误判为目标行业 | 区分主要目标与简单提及 | 构念边界控制 |
| 行业代码过度精确 | 三位数和四位数分层映射及层级一致性检查 | 层级一致性 |
| confidence 如何使用 | 多轮 confidence 加总并设置严格阈值 | 结果合成 |
| 人工标签不稳定 | 每份三人独立标注，多数票与全体一致双口径 | 人工基准稳健性 |
| 分类总体表现 | 混淆矩阵、Accuracy、Precision、Recall、F1 | 内部效度 |
| LLM 是否优于传统方法 | 与 Logistic、Random Forest、BERT 比较 | 基准效度 |
| 构造变量是否有现实含义 | 预测补贴、税收减免、融资和企业进入 | 外部效度 |
| 是否只是复制传统指标 | 吸收城市×行业×五年规划周期固定效应 | 增量效度 |

## 9. 对当前绿色披露/漂绿项目的可借鉴方案

该论文的方法可以对应到当前项目的 Layer A、Layer B 和公司年度 Greenwashing 构造，但不宜机械复制全部流程。

## 9.1 Layer A：绿色候选词或候选句召回

可以借鉴：

1. 为“绿色相关”提供正例、反例和边界案例；
2. 要求模型返回命中的原文句子及位置；
3. 程序检查返回句子是否确实出现在原年报；
4. 将候选召回和绿色相关性判断分开；
5. 对孤立词和上下文中的词分别判断；
6. 对模型未召回文本进行遗漏审计。

但需要强调，该论文主要检验的是分类 Precision/Recall，并未解决信息检索阶段的完整召回问题。因此，当前项目仍应单独做未召回句子的抽样审计。

## 9.2 Layer B：实质性与象征性绿色披露分类

最值得借鉴的是把当前一次性判断改成多阶段证据链：

### 第一阶段：证据抽取

要求模型从句子或上下文中分别提取：

- 行为主体；
- 环保行动；
- 行动对象；
- 实施状态或时间；
- 支持判断的原文。

### 第二阶段：规则判断

依据冻结的四项规则判断：

1. 行为主体是否为公司或其控制主体；
2. 是否存在具体环保行动；
3. 行动是否已经实施或正在实施；
4. 是否只是目标、计划、口号、外部要求或行业背景。

### 第三阶段：独立复核

- 由另一模型在不知道第一模型最终标签的情况下复核；
- 对分歧、低置信度和边界样本交给人工；
- 保留两轮原始证据、理由、标签和最终裁决。

### 第四阶段：程序核验

- 验证引用句是否存在于原文本；
- 验证返回格式；
- 检查判断与子问题是否逻辑一致；
- 检查 `judgment = 1` 时是否至少有主体、行动和实施状态证据。

## 9.3 建议的多轮合并规则

不建议直接复制该论文未经校准的 90 分 confidence 阈值。更合适的方法是先使用人工验证集校准：

1. 在开发集上估计不同 confidence 区间的真实 Precision；
2. 冻结阈值后在独立测试集上评价；
3. 高置信度且多模型一致的样本自动通过；
4. 多模型分歧或低置信度样本进入人工审查；
5. 报告自动通过率、人工审查率和各路径的错误率。

可以考虑如下规则：

- 两个模型均判 1 且均提供完整直接证据：最终判 1；
- 两个模型均判 0：最终判 0；
- 标签分歧、证据不完整或 confidence 低于开发集阈值：人工裁决。

## 9.4 人工 gold set 的改进设计

可参考该论文使用：

- 从总体随机抽取样本，而不是只抽模型正类；
- 每条由 3 名人工独立盲标，或 2 名人工加独立裁决；
- 正式培训和详细 coding manual；
- 同时报告人工不一致率；
- 报告多数票和完全一致样本上的模型表现；
- 给出混淆矩阵、Precision、Recall、F1 和 Accuracy。

在此基础上，当前项目最好再增加：

- Cohen’s/Fleiss’ \(\kappa\)；
- MCC 和 balanced accuracy；
- 各指标 bootstrap 95% 置信区间；
- 按年份、行业、句子长度、关键词和 confidence 分组；
- 按总体类别比例加权还原整体表现。

## 9.5 外部效度

可模仿论文的“支持性政策应预测更多补贴和进入”逻辑，为 Greenwashing 建立有方向的外部检验：

- Greenwashing 是否预测未来环境处罚；
- 是否预测 ESG 争议和环境负面新闻；
- 是否预测环境评级下调；
- 实质性行动标签是否与环保投入、在建环保工程或排污数据相关；
- 控制已有文本词典指标后，LLM 变量是否仍有增量解释力。

应明确这些是预测或构念效度检验，不能自动解释为因果效应。

## 10. 对该论文方法的评价

## 10.1 优点

1. **验证规模较大**：2,000 份随机文件、每份三人标注；
2. **防幻觉流程清晰**：原文证据、证据核验、任务拆分和抽取—分类分离；
3. **不是单模型自我确认**：结合 Gemini 多版本和 GPT-4o-mini；
4. **人工在环**：人工审查错误总结和反例，而非完全依靠 AI 自审；
5. **明确承认人工不一致**：同时采用多数票和全体一致样本；
6. **有传统方法基准**：与 TF-IDF、Random Forest 和 BERT 进行比较；
7. **有外部效度**：验证 LLM 政策变量与现实企业行为之间的关系；
8. **有增量效度**：证明 LLM 指标不是传统五年规划指标的简单替代。

## 10.2 局限

1. NBER 工作论文尚未经过正式期刊同行评审；
2. 核心人工验证主要集中在“是否属于产业政策”，对政策工具、行业映射和连续评分的人工指标披露不足；
3. 没有报告人工标注的 \(\kappa\) 或 \(\alpha\)；
4. 没有为 Precision、Recall 和 F1 报告置信区间；
5. confidence score 是模型自报分数，其统计校准没有展示；
6. 多轮阈值经过随机样本实验确定，但开发样本和最终独立测试样本的隔离程度披露不够清楚；
7. temperature = 0 不能保证 API 输出完全确定；
8. 跨模型比较能够降低同源错误，但多个模型可能仍共享训练数据和偏差；
9. 外部结果符合政策方向是重要效度证据，但不能反向证明每一条文本标签均正确；
10. 表 A1 中 LLM F1 为 0.7813，与正文多数票全样本的 79.5% 略有口径差异，可能来自三次测试划分平均与全样本评价的不同，引用时应说明口径。

## 11. 最终结论

这篇论文解决 LLM 文本识别检验和稳健性问题的总体思路可以概括为：

> **严格定义构念，以反例明确边界；将长文本复杂任务拆分为证据提取和分类；要求模型返回可核验的原文、理由和置信度；通过多模型、多轮和人工在环迭代修正；最后用随机人工 gold set、传统分类器和现实经济结果三重验证。**

对当前绿色披露分类项目，最值得直接采用的不是具体模型或 `90/180` 阈值，而是以下五项原则：

1. **先提取证据，再做判断**；
2. **所有正类判断必须能回溯到原文中的主体、行动和实施状态**；
3. **基于错误分析建立反例库，并由人工确认后冻结 coding manual**；
4. **使用多人工随机 gold set，同时报告人工分歧和完整分类指标**；
5. **用环境处罚等外部变量验证最终 Greenwashing 构念的现实含义和增量效度**。

该论文为“如何在百万级长文档上建立可审计、低幻觉的 LLM 文本测量流水线”提供了很强的实践范式，但不能替代当前项目对中文年报、Qwen 模型和实质性绿色行动构念所做的独立人工验证。
