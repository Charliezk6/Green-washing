# 审计师行业专长与漂绿首轮验证计划

## 1. 样本与核心口径

- 以现有 [`Y_variable_origional/greenwashing_panel_all_industries_2021_2024.csv`](Y_variable_origional/greenwashing_panel_all_industries_2021_2024.csv) 为公司—年度母样本，证券代码统一为六位，限定所有变量构造状态完整的 A 股公司。
- 合并事务所名称、审计收费、审计意见及基础财务与治理控制变量；事务所更名、合并和分所名称统一到同一审计机构口径。
- 主分析先保留全行业，以增加四年面板中的行业专长变动；制造业、重污染行业作为理论更贴近的子样本检验。
- 在研究开始前核对 `GI` 的经济含义。现有脚本 [`Y_variable_origional/add_baseline_continuous.py`](Y_variable_origional/add_baseline_continuous.py) 使用 `GI_z_行业年度 - ESGE_z_行业年度`；只有当较高 `GI` 表示较强绿色行动/主张时，该差值才可解释为“披露或主张相对绩效过高”。若 `GI` 实际表示实质性披露占比，则同时构造 `象征性占比=Y/(X+Y)`，避免漂绿方向解释错误。

## 2. 构造事务所行业专长

- 主指标采用事务所 `a` 在行业 `j`、年份 `t` 的客户资产加权市场份额：`MS_a,j,t = 事务所同行业客户总资产 / 该行业全部客户总资产`。
- 主处理变量定义为行业—年度市场份额第一名 `Specialist_top1`；连续市场份额 `Specialist_share` 作为共同主结果，避免结论依赖人为阈值。
- 稳健性口径依次使用：审计收费加权份额、客户数量份额、市场份额超过 10%、以及“市场份额和事务所客户组合中的行业占比均较高”的双重份额法。
- 行业采用现有 `证监会行业新`，并设置行业—年度最小样本门槛；小样本行业合并到上级行业或从专长识别中剔除，同时报告敏感性结果。

## 3. 漂绿变量设置

- 主因变量使用连续指标 `Greenwashing连续_基准`，避免二元化损失信息。
- 至少准备三个替代结果：现有二元 `Greenwashing`、`象征性披露占比=Y/(X+Y)`、以及“绿色披露指标对 E 得分和基本面的回归正残差”形成的超额披露指标。
- 分别回归 `GI/绿色沟通` 与 `E得分/环境绩效`，判断行业专长降低差距究竟来自减少夸张披露，还是对应更好的环境表现；不能只报告差值回归。
- 对 `X+Y=0`、行业内无方差以及 E 得分缺失分别编码，不将技术缺失机械填零。

## 4. 首轮基准回归

- 估计：`GW_it = β Specialist_it + Controls_it + CompanyFE + YearFE + ε_it`；主标准误按公司聚类。
- 控制变量采用审计文献常见且不过度控制的一组：公司规模、杠杆率、ROA、成长性、现金流、企业年龄、国企、第一大股东持股、董事会独立性、Big4/头部所、审计收费、审计任期和非标审计意见。
- 因为公司固定效应已经吸收不变的行业属性，主模型不再同时加入普通行业固定效应；补充规格使用行业×年度固定效应以吸收行业年度环保冲击。
- 同时报告 `Specialist_top1` 和连续市场份额的系数、经济量级、置信区间、样本数、公司数、组内变动及调整后拟合优度，而不只报告显著性。

## 5. 先验证识别条件，再解释结果

- 描述使用专家与非专家事务所企业的处理前特征、漂绿均值和行业年度分布，并检查专家身份在公司内部是否有足够变化；若几乎没有变化，公司固定效应结果会缺乏识别力。
- 将核心解释变量滞后一期，估计 `GW_it` 对 `Specialist_i,t-1`，降低同年反向选择干扰；四年样本下不把该处理解释为充分因果识别。
- 对聘用专家审计师的倾向实施熵平衡或逆概率加权，平衡规模、绩效、治理、审计需求和行业年度特征，再重复基准回归。
- 做未来值安慰剂：用 `Specialist_i,t+1` 解释当前漂绿；若未来专家身份同样显著，应把结果解释为审计师选择或预趋势，而非监督作用。
- 只有在换所样本量和处理前期足够时才做事件研究；当前 2021–2024 四年不足以支撑复杂动态 DID，首轮不把它列为必要结果。

## 6. 理论导向的补充检验

- 在制造业、重污染行业、存在环境处罚或环境财务风险较高的公司中重复估计；若行业知识机制成立，负向关系应在环境事项更专业、更可核验的情境下更强。
- 检验客户重要性调节：以单一客户审计收费占事务所客户收费的比例近似经济依赖；预期客户越重要，行业专长的抑制作用越弱。
- 检验 Big4/头部所与行业专长是否分别起作用，避免把事务所品牌规模误当成行业知识。
- 使用行业—年度内随机置换专家身份形成安慰剂分布，确认结果不是专长定义和行业结构机械生成。

## 7. 结果判定与下一阶段门槛

- 只有当行业专长在连续漂绿、至少一个替代漂绿指标、滞后模型及平衡样本中方向一致，并且未来值安慰剂不成立，才认为存在值得深入识别的稳定关系。
- 若行业专长只降低绿色披露而不改善披露—绩效背离，应解释为披露收缩，不能直接称为抑制漂绿。
- 若首轮关系稳定，下一阶段再扩展年份并优先采用事务所处罚、合并/退出等供给冲击，或共享审计师的同行环境处罚知识扩散设计，推进因果识别。
- 最终产出包括变量定义与样本流失表、描述统计、相关性与组间平衡、基准回归、替代变量、滞后与安慰剂、异质性结果，以及一份明确区分“相关证据”和“因果证据”的结论说明。
