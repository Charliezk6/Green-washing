# 行业专家客户选择方程：复现与论文写作说明

## 1. 检验目的

本文件夹对应论文“内生性识别与可信度检验”中的第一个客户自选择检验方法：**行业专家客户选择方程**。

核心问题是：观察到行业专家事务所客户的漂绿程度较低，是否可能并非由行业专家审计产生，而是因为本来就不愿漂绿、治理更好、更加重视声誉或具有更强信息披露能力的企业，主动选择了行业专家事务所。

该方法不把选择方程解释为因果第一阶段，也不把 `IMS_D` 当作工具变量。它的作用是识别企业在聘用或继续聘用行业专家事务所之前，既有企业特征是否系统性预测行业专家选择。

当前结果应与论文主回归的表述保持一致：主回归识别的是行业专家与漂绿之间的条件相关关系；客户选择方程用于评估这种关系是否可能受到客户主动选择的影响。

## 3. 数据来源

脚本读取已经由基准回归程序构造完成的面板：

```text
Regression_reproduction/outputs/baseline/已构造基准回归变量的面板.csv
```

该文件包含：

- 企业年度标识：`证券代码`、`时间`；
- 行业标识：`ExpertiseIndustryCode`；
- 行业专家变量：`IMS`、`IMS_D`；
- 漂绿变量：`Greenwashing连续_基准`；
- 漂绿构成项：`GI_z_行业年度`、`ESGE_z_行业年度`；
- 已构造财务、治理和审计控制变量。

脚本不会重新计算漂绿指标，也不会重新计算行业专家市场份额。它只负责按企业—年度规则生成滞后变量、构造选择样本、估计模型和输出诊断结果。

## 4. 变量与滞后规则



### 4.1 因变量

选择方程的因变量为当期行业专家虚拟变量：

```text
IMS_D_t
```

当事务所在相应行业的审计市场份额达到 10% 时，`IMS_D=1`；否则为 0。

### 4.2 核心滞后变量

主解释变量均使用处理发生前一期的企业特征：

- `L_Greenwashing连续_基准`：滞后一期漂绿；
- `L_GI_z_行业年度`：滞后一期实质性披露相关指标；
- `L_ESGE_z_行业年度`：滞后一期环境绩效指标；
- `L_IMS_D`：滞后一期行业专家状态。



### 4.3 控制变量

滞后财务控制变量：

```text
L_Size, L_Lev, L_ROA, L_CFO, L_Growth, L_FirmAgeLog
```

滞后治理控制变量：

```text
L_SOE, L_Dual, L_BoardSize, L_IndependentDirectorRatio
```

滞后审计控制变量：

```text
L_Big4, L_LnAuditFee, L_AuditorTenure, L_IsChangeFirm
```

变量按照 `证券代码` 和 `时间` 排序。只有当前年度与上一条企业观测的年份差等于 1 时，才生成滞后变量；如果企业缺失上一年度，滞后变量设为缺失。由于面板起始于 2021 年，选择方程的有效滞后样本从 2022 年开始。

## 5. 模型规格

所有规格包括年度固定效应和 `ExpertiseIndustryCode` 行业固定效应，标准误按企业 `证券代码` 聚类。

### S1：滞后漂绿选择模型


Pr(IMSD_{i,t}=1)=\Lambda(\alpha+\theta L.Greenwashing_{i,t-1}+\delta'X_{i,t-1}+YearFE_t+IndustryFE_j).


S1 检验企业既有漂绿水平是否预测其下一期选择行业专家事务所。若滞后漂绿系数为负，表示漂绿程度较低的企业更可能选择行业专家；但该结果只能说明选择模式，不代表行业专家导致漂绿下降。

### S2：漂绿构成项选择模型

S2 用 `L_GI_z_行业年度` 和 `L_ESGE_z_行业年度` 替代滞后漂绿，并保留相同控制变量。

由于：

```text
Greenwashing连续_基准 = GI_z_行业年度 - ESGE_z_行业年度
```

S2 与 S1 分列估计，不能在同一个选择方程中同时放入滞后漂绿及其两个构成项。

### S3：控制既有专家关系

S3 在 S1 的基础上加入 `L_IMS_D`：


Pr(IMSD_{i,t}=1)=\Lambda(\alpha+\theta L.Greenwashing_{i,t-1}+\delta'X_{i,t-1}+\rho L.IMSD_{i,t-1}+YearFE_t+IndustryFE_j).


S3 是本方法中最重要的补充规格。`L_IMS_D` 控制客户是否已经处于行业专家审计关系，从而区分：

1. 客户总体上是否更可能聘用行业专家；
2. 已有行业专家关系是否具有持续性；
3. 在控制既有专家关系后，漂绿是否仍然预测当期专家选择。



### S4：进入行业专家状态

S4 将样本限制为 `L_IMS_D=0` 的企业，因变量仍为当期 `IMS_D`。该模型检验原本不是行业专家客户的企业是否在下一期进入行业专家状态。

S4 的“进入”不等同于“换所后进入”。如果企业没有更换事务所，但由于行业市场份额变化导致 `IMS_D` 从 0 变为 1，也会被 S4 纳入。换所后进入专家的独立检验属于第三个方法。

## 6. 估计方法与 Logit 



### 6.1 Logit 主模型

主估计方法为带年度和行业固定效应的二元 Logit，并报告：

- Logit 系数；
- 优势比 `exp(系数)`；
- 平均边际效应；
- 按企业聚类的标准误。

当前脚本加入固定效应可识别性处理：在 Logit 估计前，按具体模型样本剔除 `IMS_D` 在行业内恒定的行业类别。

这一步不是删除异常企业，也不是根据结果变量筛选企业，而是删除无法在含行业固定效应的 Logit 中识别的固定效应类别。每个规格的剔除数量和行业代码记录在：

```text
outputs/diagnostics/model_diagnostics.csv
```

当前运行结果为：


| 规格  | 原始样本  | Logit样本 | 剔除行业数 | 剔除观测数 | Logit处理组数 | 是否收敛 |
| --- | ----- | ------- | ----- | ----- | --------- | ---- |
| S1  | 5,431 | 5,419   | 2     | 12    | 1,210     | 是    |
| S2  | 5,431 | 5,419   | 2     | 12    | 1,210     | 是    |
| S3  | 5,431 | 5,419   | 2     | 12    | 1,210     | 是    |
| S4  | 4,271 | 3,556   | 11    | 715   | 303       | 是    |


S4 被删除的 715 个观测全部来自当期 `IMS_D=0` 的行业，因而没有删除任何处理组，但 S4 的有效 Logit 样本明显小于 LPM 样本。论文中必须分别报告 LPM 样本和 Logit 有效估计样本，不能把两者写成同一批观测。

### 6.2 LPM 对照模型

LPM 是二元选择模型的函数形式稳健性检验。其系数可直接解释为概率变化，但不替代 Logit 主模型。

如果 Logit 和 LPM 的核心变量方向一致，可以说结论对函数形式具有一定稳定性；如果显著性不同，应以 Logit 平均边际效应和置信区间为主，并说明 LPM 的差异。

## 7. 复现方法

在项目根目录执行：

```bash
python "validation/P1/01_行业专家客户选择方程/run_selection_models.py"
```

脚本运行后会覆盖 `outputs/tables/` 和 `outputs/diagnostics/` 中的结果文件。

建议复现顺序：

1. 确认基准回归面板已经存在；
2. 执行选择方程脚本；
3. 检查 `model_diagnostics.csv` 中四个 Logit 是否成功且收敛；
4. 检查 `sample_summary.csv` 中各规格样本量；
5. 阅读 Logit 系数和平均边际效应；
6. 用 LPM 结果检查方向是否一致；
7. 再将结果整理进论文表格和文字。



## 8. 当前结果摘要



### 8.1 样本

S1—S3 使用 5,431 个企业年度观测、2,333 家企业；S4 使用 4,271 个观测、1,938 家企业。S1—S3 的当期行业专家处理组为 1,215 个，处理比例为 22.37%；S4 的进入专家观测为 303 个，进入比例为 7.09%。

### 8.2 S1：滞后漂绿

Logit 在删除无行业内因变量变异的 12 个观测后成功估计。`L_Greenwashing连续_基准` 的 Logit 系数为 -0.0537，p=0.1017；LPM 系数为 -0.00964，p=0.0567。因此，方向一致，但 Logit 未达到 10% 显著水平，当前应表述为弱的、对模型形式不完全稳健的负向选择关系。

### 8.3 S2：构成项

`L_GI_z_行业年度` 与 `L_ESGE_z_行业年度` 的结果应以 `logit_coefficients.csv` 和 `logit_average_marginal_effects.csv` 为准。论文中应分别报告两个构成项，不应将其与 S1 的滞后漂绿系数直接比较为同一含义。

### 8.4 S3：既有专家关系

S3 的核心 Logit 结果如下：


| 变量                    | Logit系数  | 优势比    | 平均边际效应   | p值     |
| --------------------- | -------- | ------ | -------- | ------ |
| `L_Greenwashing连续_基准` | -0.00972 | 0.9903 | -0.00079 | 0.7674 |
| `L_IMS_D`             | 3.8330   | 46.20  | 0.31243  | <0.001 |


S3 的 LPM 结果为：

- `L_Greenwashing连续_基准`：-0.00114，p=0.6866；
- `L_IMS_D`：0.67683，p<0.001。

因此，控制上一期专家状态后，滞后漂绿不再预测当期行业专家选择，而既有专家关系具有极强持续性。结合转移矩阵，上一期为专家的客户下一期继续为专家的比例约为 78.8%；上一期不是专家的客户下一期进入专家的比例约为 7.4%。

### 8.5 S4：进入专家状态

S4 中 `L_Greenwashing连续_基准` 的 Logit 系数为 -0.0240，p=0.6144；平均边际效应为 -0.00170，p=0.6144。因此，没有证据表明原非专家客户的既有漂绿程度显著预测其下一期进入专家状态。

## 9. 论文写作边界



### 可以写

- 客户选择方程用于检验客户自选择模式；
- S1 未控制既有专家关系时，滞后漂绿的负向关系较弱；
- S3 控制 `L_IMS_D` 后，滞后漂绿不再显著；
- `L_IMS_D` 对当期 `IMS_D` 有显著且经济意义较大的正向预测作用；
- S4 未发现滞后漂绿显著预测进入专家状态；
- 结果表明客户—审计师关系持续性是选择过程的重要特征。



### 不应写

- “客户选择方程证明了行业专家的因果效应”；
- “不显著证明不存在客户自选择”；
- “S4 等同于换所后选择行业专家”；
- “控制选择方程后已经完全解决内生性”；
- “Logit 与 LPM 使用完全相同的估计样本”；
- “客户治理更好导致其选择行业专家”，除非明确说明这是选择相关性而非因果机制。



## 10. 结果解释建议

论文中建议将本方法定位为：

> 为评估客户自选择是否可能解释行业专家与企业漂绿之间的负向关系，本文估计行业专家客户选择方程。模型以当期 `IMS_D` 为因变量，以滞后一期漂绿、漂绿构成项以及企业财务、治理和审计特征为解释变量，并控制年度和行业固定效应。结果显示，未控制上一期专家关系时，滞后漂绿与行业专家选择之间仅呈现较弱的负向关系；加入 `L_IMS_D` 后，该关系消失，而上一期专家状态显著预测当期专家状态。原非专家客户进入专家状态的分析也未发现滞后漂绿具有显著预测力。总体而言，结果不支持“低漂绿企业系统性主动选择行业专家”这一解释，但表明客户—审计师关系存在显著持续性。因此，客户自选择不能被简单地视为不存在，主回归结果仍应谨慎解释为条件相关关系，而不是无条件因果效应。

这一段需要根据后续第二、第三种客户自选择检验的结果进行更新。当前 README 只记录第一种方法，不代表整个内生性识别部分已经完成。

## 12. 复现注意事项

- 不要跨缺失年度生成滞后项；
- 不要将当期审计费用、当期审计任期等可能受当期事务所选择影响的变量替代为主滞后控制变量；
- 不要在 S2 中同时加入 `L_Greenwashing连续_基准`、`L_GI_z_行业年度` 和 `L_ESGE_z_行业年度`；
- 不要用 S4 代替换所样本分析；
- 不要手工删除结果表中的不显著变量；
- 重新运行后应同时检查样本量、固定效应剔除情况、模型收敛和核心变量方向；
- 如果输入面板、行业分类、`IMS_D` 阈值或缺失值规则发生变化，应在结果归档中记录版本变化；
- 若后续把结果整理为论文表格，应保留 Logit 和 LPM 的估计样本差异说明。
