# 漂绿与审计专长回归计划

## 1. 数据与变量核验
- 检查公司—年度唯一性、缺失值、异常值及变量类型，明确各模型的有效样本数。
- 主被解释变量：`Greenwashing连续_基准`；二元替代变量：`Greenwashing`。
- 核心解释变量分别使用 `IMS`、`IMS_D`，避免二者同时进入同一模型；`IPS`、`IPS_D`作为替代度量。
- 从现有字段构造控制变量：公司规模 `ln(TotalAssets)`、资产负债率、盈利能力、经营现金流、成长性、公司年龄、产权性质、董事会规模、独董比例、两职合一、四大/国内十大会计师事务所、审计收费、审计任期、事务所变更等。

## 2. 基准回归
- 先报告不加控制变量的一元 OLS，再逐步加入公司财务特征、治理特征和审计特征，观察核心系数稳定性。
- 主模型加入年度固定效应和行业固定效应。
- 标准误优先按公司聚类，处理同一公司跨年度误差相关；同时报告稳健标准误结果用于对照。
- 分别估计 `IMS`和`IMS_D`模型，重点检验其系数方向、显著性与经济意义。

## 3. 稳健性与异质性检验
- 用 `IPS`、`IPS_D`替换行业专长指标。
- 用二元`Greenwashing`进行 Logit 回归，并报告平均边际效应。
- 对连续控制变量进行1%和99%缩尾后重新估计。
- 分制造业与非制造业、分年度进行异质性检验；必要时检验组间系数差异。
- 检查多重共线性（相关系数与VIF）以及极端值对主结论的影响。

## 4. 输出与解释
- 输出样本筛选及变量构造诊断表、基准回归表、稳健性表、异质性表、VIF表和模型拟合信息。
- 保存可重复运行的Python脚本及CSV结果；如环境支持，同时输出排版好的Excel表。
- 对核心系数解释统计显著性和经济显著性，并明确哪些结果属于相关关系、哪些稳健性检验支持主结论。
