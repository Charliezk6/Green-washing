# P1 客户自选择检验代码执行计划

## 1. 目标

本执行包将《客户自选择检验计划》中的四种方法拆分为四个独立目录。各方法统一读取现有基准构造面板，但独立生成样本、模型结果和诊断文件，不修改或覆盖 `Regression_reproduction` 下的基准回归产物。

## 3. 环境与统一数据口径

- Python 3.10 或以上。
- Python 包：`numpy`、`pandas`、`scipy`、`statsmodels`、`matplotlib`。
- 默认输入：`Regression_reproduction/outputs/baseline/已构造基准回归变量的面板.csv`。
- 公司标识为 `证券代码`，年度为 `时间`，行业为 `ExpertiseIndustryCode`。
- CSV 均使用 `utf-8-sig`；证券代码按字符串读取。
- 所有脚本根据自身位置向上定位项目根目录，可从项目根目录或脚本所在目录启动。

## 4. 统一预处理规则

1. 将模型所需数值字段强制转换为数值；无法转换的值设为缺失。
2. 按 `证券代码`、`时间` 排序。只有同一企业相邻记录满足 `时间_t - 时间_{t-1} = 1` 时才保留一期滞后值。
3. 二期滞后及 `t-2` 到 `t-1` 的变化也要求年度严格连续，不跨缺失年度构造。
4. 选择和匹配仅使用 `t-1` 信息；不使用可能被当期事务所选择影响的当期审计特征。
5. `L.Greenwashing连续_基准` 与其构成项 `L.GI_z_行业年度`、`L.ESGE_z_行业年度` 不进入同一选择方程。
6. 回归固定效应为年度与行业；标准误按公司聚类。模型实际样本按各规格所需变量逐一完整案例筛选，不预先强制所有规格使用同一样本。
7. 每个方法只向自身 `outputs` 写结果。

## 5. 方法一：行业专家客户选择方程

脚本：`01_行业专家客户选择方程/run_selection_models.py`

执行规格：

- `S1`：滞后漂绿 + 滞后财务、治理和审计控制变量。
- `S2`：以滞后 GI 与滞后 ESGE 替代滞后漂绿。
- `S3`：在 S1 基础上加入 `L.IMS_D`。
- `S4`：限制 `L.IMS_D=0`，估计进入专家状态的概率。
- 每个规格估计 Logit 和 LPM；Logit 输出系数、优势比、平均边际效应及收敛信息，LPM 使用公司聚类标准误。

主要产物：

- `outputs/tables/logit_coefficients.csv`
- `outputs/tables/logit_average_marginal_effects.csv`
- `outputs/tables/lpm_coefficients.csv`
- `outputs/tables/sample_summary.csv`
- `outputs/diagnostics/model_diagnostics.csv`
- `outputs/diagnostics/lag_data_diagnostics.csv`

验收重点：S1–S4 均有独立样本统计；S4 的 `L.IMS_D` 最大值必须为 0；Logit 的收敛、警告和失败原因必须落盘，不能静默丢失模型。

## 6. 方法二：倾向得分与属性匹配

脚本：`02_倾向得分与属性匹配/run_matching.py`

### 6.1 文献基准与本研究对应关系

主 PSM 直接参照 Schroeder（2016, *The Accounting Review*, DOI: 10.2308/accr-51182）的审计质量 PSM 设计。该文为处理审计师选择与披露决策可能同时受客户特征影响的问题，先用 Probit 估计企业选择某类审计师的概率，再实施 1:1 最近邻、无放回匹配，并要求处理组和对照组倾向得分差不超过 3 个百分点；匹配后检验倾向模型全部解释变量的协变量平衡，最后在匹配样本上重新估计包含控制变量、年度和行业固定效应的完整结果方程。该文明确将 PSM 定位为缓解可观测客户特征导致的选择偏误，不能完全排除内生性。

对应到本文：

- Schroeder 的审计师选择处理变量替换为本文的 `IMS_D_t`，处理组为当期行业专家事务所客户，对照组为当期非行业专家事务所客户；
- 选择方程只使用处理发生前的 `t-1` 客户特征，不能使用可能受到当期审计师选择影响的当期变量；
- 倾向模型解释变量使用 `L.Greenwashing连续_基准`、滞后财务、治理和审计特征，并加入年度和 `ExpertiseIndustryCode` 行业控制；
- 该设计检验在可观测的既有漂绿、经营状况、治理和审计关系特征相近后，行业专家客户与非专家客户的当期漂绿是否仍存在差异。

### 6.2 主规格：Schroeder 式 PSM

1. 使用 Probit 估计：

   \[
   Pr(IMS\_D_{i,t}=1)=\Phi(\alpha+\theta GW_{i,t-1}+\delta'X_{i,t-1}+YearFE_t+IndustryFE_j).
   \]

2. 在处理组与对照组的共同支撑区间内实施 1:1 最近邻匹配，**主规格不放回**。
3. caliper 按 Schroeder（2016）的口径设为原始倾向得分绝对差不超过 `0.03`，而不是 logit 标尺标准差的 0.20 倍。
4. 若某个行业固定效应类别中的 `IMS_D` 没有变异，按照方法一的识别规则在倾向模型估计前删除，并完整报告删除行业、观测和处理组数量。
5. 匹配后对倾向模型中的全部滞后协变量报告处理组均值、对照组均值、均值差检验和标准化均值差（SMD）。Schroeder 以均值差不显著判断平衡；本文同时采用更透明的 `|SMD|<0.10` 标准。任何核心变量未通过平衡时，不能直接把该规格称为平衡匹配样本。
6. 在匹配样本中重新估计完整结果方程，而不是只比较未经调整的处理组均值：

   \[
   GW_{i,t}=\alpha+\beta IMS\_D_{i,t}+\gamma'X_{i,t-1}+YearFE_t+IndustryFE_j+\varepsilon_{i,t}.
   \]

   标准误按公司聚类。论文主表至少报告：（1）`IMS_D` 加年度和行业固定效应；（2）再次加入全部滞后协变量的完整模型。第二个模型作为与 Schroeder 论文表 5 PSM 列最接近的主结果。

### 6.3 分析边界

本方法只执行 Schroeder 式 PSM，不再保留旧的 Logit 倾向模型、`0.20 × logit(倾向得分)` 标准差 caliper、有放回 PSM 或属性匹配。连续行业专长度量 `IMS` 也不进入本方法的处理定义或结果方程；本文 PSM 只检验二元行业专家状态 `IMS_D`。

### 6.5 验收重点

- 明确记录倾向模型是 Probit、倾向得分原始标尺 caliper 为 `0.03`、1:1 匹配及主规格不放回；
- 分别报告初始样本、固定效应识别删除、共同支撑删除、caliper 内未匹配处理组、成功配对数、唯一观测数和加权观测数；
- 配对文件包含 `pair_id`、倾向得分、匹配距离、匹配角色和匹配权重；
- 倾向模型全部协变量逐项报告匹配前后均值、均值差检验和 SMD，并以 `|SMD|<0.10` 判断基本平衡；
- 匹配前后倾向得分分布和 Love plot 必须落盘；
- 匹配后结果回归同时报告固定效应简化模型和再次加入滞后协变量的完整模型，标准误按公司聚类；
- 明确说明 PSM 只平衡可观测客户特征，不能排除未观测的治理质量、声誉偏好、审计需求或反向筛选，也不能单独把匹配结果解释为因果效应。

## 7. 方法三：审计师换所样本分析

脚本：`03_审计师换所样本分析/run_switching_analysis.py`

执行步骤：

1. 根据严格连续滞后构造上一期事务所与专家状态。
2. 将 `IsChangeFirm=1` 与 `InstitutionID_t != InstitutionID_{t-1}` 交叉核验；不一致观测单独输出，主样本仅保留两者同时成立者。
3. 构造 `SwitchInExpert`、`UpgradeExpert` 和 `DeltaGW`。
4. 对换入专家执行精简 Logit/LPM；基础控制为滞后 `Size`、`Lev`、`ROA`、`SOE`、`Big4`、`AuditorTenure`、`IMS_D`，治理扩展变量分组加入。
5. 比较换入专家与换入非专家企业的事前均值和 SMD；严格存在 `t-2` 时补充事前漂绿变化比较。
6. 估计 `DeltaGW` 的描述性变化模型。

主要产物：

- `outputs/tables/switching_model_coefficients.csv`
- `outputs/tables/pre_switch_comparisons.csv`
- `outputs/tables/pretrend_change_comparison.csv`
- `outputs/tables/delta_gw_regression.csv`
- `outputs/tables/sample_summary.csv`
- `outputs/diagnostics/switch_flag_inconsistencies.csv`
- `outputs/diagnostics/model_diagnostics.csv`

验收重点：主换所样本中的两项换所判断全部为真；报告换所样本量与换入专家事件数；完全分离、未收敛、事件数过少或聚类数不足均记录为诊断，不把模型失败误报为零效应。

## 8. 方法四：逆倾向得分加权

脚本：`04_逆倾向得分加权/run_ipsw.py`

### 8.1 倾向得分与样本

- 处理变量为当期二元 `IMS_D_t`，结果变量为当期 `Greenwashing连续_基准_t`；选择方程只使用严格连续滞后一期的处理前变量。
- W1 使用 `L.Greenwashing连续_基准` 加滞后财务、治理和审计协变量；W2 用 `L.GI_z_行业年度` 和 `L.ESGE_z_行业年度` 替代滞后漂绿，不能将三者同时放入同一选择方程。
- 分别对每个规格构造完整案例样本，以 Logit 估计倾向得分，并控制年度和 `ExpertiseIndustryCode` 固定效应。处理变量在年度—行业单元内无变异时，该单元不参与倾向模型估计，并报告剔除数量。

### 8.2 权重与共同支撑

- 在处理组和对照组倾向得分交叠区间内保留共同支撑样本，并报告被删除的处理组、对照组和企业数。
- 主规格为共同支撑样本上的稳定化 ATE 权重：处理组为 `Pr(IMS_D=1)/e`，对照组为 `Pr(IMS_D=0)/(1-e)`。
- 稳健性规格包括 ATT 权重（处理组为 1、对照组为 `e/(1-e)`）、不截尾 ATE 以及 0.5%/99.5% 截尾 ATE。主 ATE 权重按 1%/99% 分位数截尾。
- 每种权重均报告均值、标准差、分位数、最大值和有效样本量 `ESS=(Σw)^2/Σw^2`，不把加权观测量解释为新增企业。

### 8.3 平衡与结果方程

- 对 W1/W2 的各个权重逐项报告加权前后滞后协变量的均值、方差、方差比和标准化均值差；加权后 `|SMD|<0.10` 作为基本平衡标准。
- 主结果使用主 ATE 权重估计 `Greenwashing连续_基准_t ~ IMS_D_t + 年度固定效应 + 行业固定效应`；另报告加入对应滞后协变量的增强加权结果方程。标准误按公司聚类。
- 以 ATT、未截尾 ATE 和 0.5%/99.5% 截尾 ATE 重复估计处理变量和固定效应模型；连续 `IMS` 不直接应用二元 IPSW。

### 8.4 产物与验收

- 表格：`sample_flow.csv`、`propensity_models.csv`、`weight_diagnostics.csv`、`covariate_balance.csv`、`outcome_regressions.csv`、`run_summary.csv`。
- 诊断：`model_diagnostics.csv`、`common_support_exclusions.csv`、`balance_failures.csv`；图形：`propensity_score_overlap_W1.png`、`propensity_score_overlap_W2.png`、`weight_distribution_W1.png`、`weight_distribution_W2.png`、`love_plot_W1.png`、`love_plot_W2.png`；数据：`ipsw_analysis_data_W1.csv`、`ipsw_analysis_data_W2.csv`。
- 缺列、模型不收敛、完全分离、没有共同支撑或极端权重导致有效样本量严重下降时，必须写入诊断；不得静默跳过或将失败规格误报为零效应。

## 9. 运行顺序

在项目根目录依次执行：

```powershell
python "validation/P1/01_行业专家客户选择方程/run_selection_models.py"
python "validation/P1/02_倾向得分与属性匹配/run_matching.py"
python "validation/P1/03_审计师换所样本分析/run_switching_analysis.py"
python "validation/P1/04_逆倾向得分加权/run_ipsw.py"
```

PSM 的 `0.03` caliper 按 Schroeder（2016）预先固定，不通过命令行修改。若需测试其他 caliper，应建立独立敏感性分析脚本或版本，不能覆盖本文主规格结果。

## 9. 异常处理与最终核验

- 缺失字段：脚本启动时一次性列出缺失字段并停止，避免运行中产生不完整结果。
- Logit 完全分离或奇异矩阵：保存错误类型和消息；LPM 仍独立执行，不能以 LPM 替代失败的 Logit。
- Probit 未收敛、固定效应无因变量变异或协方差矩阵不可逆：停止 PSM 并输出明确诊断，不静默改用 Logit。
- 无共同支撑或 `0.03` caliper 内无对照：将相应处理观测记为未匹配，并在样本流程表中报告。
- 无放回匹配中同一对照最多使用一次；若候选耗尽则将处理观测记为未匹配。
- 聚类组过少：在诊断中警告；结果仅作为描述性证据。
- 最终应核对四个方法的输入行数一致、严格连续滞后规则一致，同时允许因规格所需变量不同而具有不同最终样本数。
