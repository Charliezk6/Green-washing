# Mechanism

## M1 事务所内部形成的统一的工作规则（如披露模板）会影响企业的披露表述

### M1.1 事务所会成为其客户群的common hub

Francis这篇文章说BIG 4会投入高昂的固定成本编写内部技术指南，而这些指南不仅供一线审计员核查使用，还会通过付费订阅或客户服务网络直接提供给客户公司的管理层（CFO及财务团队）。当客户公司面临新的或复杂的披露要求时，为了降低合规成本与被出具非标意见的风险，管理层会直接采纳审计师指南中的披露范例。

```
例如：一家客户公司的 CFO 在编制报告遇到复杂或新型的披露议题（例如新准则落地、环境负债评估、气候风险披露等）时，通常会主动向其所属四大事务所的技术部门寻求指导。
```

田高良的文章中有说会计师事务所会为每个细分行业建立包含常见风险事项和应对程序的数据库，形成组织级的“知识资产”，而审计团队会围绕高频案例进行培训并优先匹配该数据库。

刘浩的文章表示各会计师事务所都有独特的内部工作规则、对准则与披露规范的理解以及质量控制程序，用来指导和规范审计工作，从而在文本披露上呈现出各自的“事务所风格”，使同一事务所审计的公司在文本特征上具有更高的一致性。

同时Johnston2021的文章中说事务所应用的规则会在客户群内传播，它可以影响财报账户的归集、调整和披露。

### M1.2 个体审计师会受到事务所的规则限制

当一线审计团队的成员使用相同的软件模板去审核不同客户的报表与披露时，系统预设的重要性阈值（Materiality thresholds）和合规性检查项会迫使审计师按照模板让不同客户删除不符合该所风格的披露表述，或补充该所系统要求的关键披露要素。这种技术系统的刚性约束，使得共享同一审计事务所的企业在披露的特性上趋同。

田高良2021这篇文章提到会计师事务所具有专业的准则研究人员， 会对准则变更进行提前的深入研究， 并形成工作范式、 工作规则和整体的思维模式提供给个人注册会计师。因此个人会按照事务所的思维模式和工作范式系统地偏爱识别某些事项。

Johnston2021这篇文章提到事务所的工作规则会深刻影响个体审计师

## M2 客户把披露工作交给审计师，审计师再把经验复制给其他客户

### M2.1 客户自身的披露质量参差不齐，需要审计师复核并修改

一些公司可能本身财务能力不足，还有的是不认真完成披露任务，指望审计师修改。Mauritz的文章中通过访谈了 8 位项目合伙人，讲到了具体影响披露的操作：

```
1. 把审计核对清单交给客户，客户按清单补话题，结构因此趋同。
2. 直接让客户去看其他客户或竞争对手怎么写。
3. 指出缺哪一类话题，并给出“可以这样写”的替代表述；管理层通常照收。
4. 用邮件给出替代措辞，理由是降低诉讼风险、满足准则。
5. 在稿子上蓝笔修改。
6. 小客户编制能力不足时，项目组与客户一起改管理层报告，极端情况下由审计师落笔。受访者把这称为审计和咨询之间的灰色地带，也是职业道德上的自我复核风险。
```

## M3 个体审计师会对客户的披露内容产生实质性影响

H shi的文章发现个人审计师确实存在“审计风格”，并且会独立影响客户财务报表的可比性。​ 即使控制了审计事务所和审计分所的影响，由同一名审计师签字的企业，其财务报表仍表现出更高的相似性。

张勇的文章发现签字会计师组成的审计项目团队是会计师事务所的基本决策单元，注册会计师的个体特征（知识、经验、专业技能与思维模式）直接决定了沟通与判断的差异，因此派往配对企业的签字会计师重合程度越高，企业间的政策相似性越强。

## M4 审计师的影响力能够从强制性财务报表审计（mandatory audit）延伸到自愿性信息披露（voluntary reporting）

### M4.1 咨询服务与合规指导

管理层经常将审计师视为专业技术资源，利用其专业知识判断拟披露的 Non-GAAP 盈余指标及其呈现方式是否符合 SEC 的监管规定（Frank2024）。

张勇2022 这篇文章说明了组织间模仿源于降低决策环境不确定性与满足合法性需求两个动因，而会计师事务所在及时、准确地掌握各联结客户选择情况方面具有天然优势，能够围绕行业同行做法提供“咨询服务”或信息参照。

### M4.2 地方审计办公室层面的统一风格与知识网络来让客户采纳意见

尽管四大会计师事务所的全国性机构会发布关于 Non-GAAP 披露的指导文件，但这些规定在实际业务中的具体应用，主要由地方审计办公室推动。当同一家地方审计办公室的客户接受并执行这种统一指导时，它们的 Non-GAAP 披露实践就会逐渐趋同，从而实现更高程度的标准化和更强的监管合规性。
