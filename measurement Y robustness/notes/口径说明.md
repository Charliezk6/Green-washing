# 口径说明

本文件固定 `measurement Y robustness` 的变量定义。实现脚本时按这里的公式写，不在脚本里另改标准化或词表。

## 样本与回归

- 起点是 `Regression/outputs/paper_tables/common_sample_15381.csv` 的 15,381 行。
- 证券代码补成 6 位。年份用数值 `时间`。
- 完整模型控制变量：`Size`、`Lev`、`ROA`、`CFO`、`Growth`、`FirmAge`、`SOE`、`Dual`、`BoardSize`、`IndependentDirectorRatio`、`Big4`、`LnAuditFee`、`AuditorTenure`、`IsChangeFirm`。
- 固定效应：`C(时间)` 与 `C(ExpertiseIndustryCode)`。
- 标准误按 `证券代码` 聚类。
- 每个新因变量各跑两列：`IMS`、`IMS_D`。只估计含全部控制与固定效应的一列，不再重复一元到逐步加控制的嵌套。
- 不缩尾因变量。控制变量沿用共同样本里已经缩尾的数值。
- 某因变量缺失的行只从该列回归中去掉，并在表注写剩余样本量。不回写主面板。

行业—年 z 分数与主回归相同：分组为 `时间 × ExpertiseIndustryCode`，标准差 `ddof=1`。组内非缺失观测不超过 1，或标准差为 0 或缺失时，该组 z 分数记缺失。

## 01 不利具体句

只统计 Layer B 中 `status == success` 且 `judgment == 1` 的记录。句子字段用 `sentence`。

一句算不利具体句，当句子包含下列任一用语：

`处罚`、`罚款`、`罚金`、`超标`、`违规`、`违法`、`责令`、`立案`、`通报`、`行政处罚`、`停产`、`限产`、`未按时`、`未完成`、`逾期`

`整改`、`排放`、`生态环境` 单独出现不算不利。完成整改和正常排放叙述会把正面行动句误判成棕色披露。

输出两行占比：

- 关键词—句子对：不利对子数 / `judgment = 1` 对子数
- 公司—年：至少有一条不利具体句的公司—年数 / 至少有一条 `judgment = 1` 的公司—年数

另存 20 条不利句和 20 条未命中句，供人工看词表是否过宽。路径：`results/tables/adverse_examples.csv`。

## 02 净正面 GI+

对每个公司—年：

- `S`：`judgment = 1` 的对子数
- `S_adv`：其中不利对子数
- `S+ = S − S_adv`
- `P`：`judgment = 0` 的对子数
- `GI+ = S+ / (S+ + S_adv + P) = S+ / (S + P)`

不利句留在分母、退出分子。这样棕色披露不会再抬高行动声称比例。`S + P = 0` 或该年 Layer B 没有成功记录时，`GI+` 缺失。

`Greenwashing+ = z(GI+) − ESGE_z_行业年度`。`ESGE_z` 用共同样本上已经算好的 `ESGE_z_行业年度`，不重算华证标准化。`z(GI+)` 在共同样本内、按同一行业—年规则新算。

主对比列的因变量是原来的 `Greenwashing连续_基准`，系数从共同样本重估一次，便于和 `Greenwashing+` 放在同一张表。

## 03 成分拆解

三列因变量，样本仍是共同样本里该列非缺失的行：

| 列 | 因变量 | 额外控制 |
|---|---|---|
| 声称侧，不控制绩效 | `GI_z_行业年度` | 无 |
| 声称侧，控制绩效 | `GI_z_行业年度` | `ESGE_z_行业年度` |
| 绩效侧 | `ESGE_z_行业年度` | 无 |

`IMS` 与 `IMS_D` 各跑这三列，共六列。解释时看控制绩效后的声称侧系数：它表示同等华证环境分下，具体行动声称是否仍更低。

## 04 处罚替代绩效

处罚从 `appendix/上市公司环保处罚总表.xlsx` 汇总，规则与 `merge_hard_env.py` 的 `load_penalty()` 相同。

- `Penalty_D`：该证券代码—年至少一条处罚记录为 1，否则 0
- `Penalty_Count`：条数，无记录为 0
- `PenaltyAmt`：`处罚金额（万元）` 加总，无记录为 0
- `LnPenaltyAmt = ln(1 + max(PenaltyAmt, 0))`

二元因变量 `GW_Penalty_D`：`GI` 严格高于同一 `时间 × ExpertiseIndustryCode` 的样本均值，且 `Penalty_D = 1`，取 1，否则取 0。用线性概率模型，固定效应与聚类不变。

连续因变量 `GW_Penalty = GI_z_行业年度 − (−PenaltyCount_z) = GI_z_行业年度 + PenaltyCount_z`。`PenaltyCount_z` 是 `Penalty_Count` 的行业—年 z 分数。组内标准差为 0 的行业—年记缺失，回归样本量会小于 15,381。表注同时给出处罚发生率 `Penalty_D` 的均值。

金额 z 分数不作主列。零金额过多时，组内标准差经常为 0。若需要，只在覆盖率表报告 `LnPenaltyAmt` 的非零公司—年数，不单开回归。

## 不纳入本目录的绩效指标

- 排放明细和碳排放：多数来自公司自己的环境披露，替换华证后仍与年报文本同源，也不能补齐 15,381。
- 绿色专利：衡量的是绿色创新数量。有专利的公司仍可以有高污染或当年环境处罚。
- 预计负债：资产负债表科目 `A002207000` 不专指环境负债。

正文用这一节的三句话说明取舍即可，不必为这三项再跑主规格。
