# 相关随机效应：组内与组间

正文主规格仍是行业 + 年份固定效应。这里用 Wooldridge (2019) 的非平衡面板 Mundlak 装置，把组内斜率和组间斜率放在同一张表里。ξ = 0 的检验用来读这两条斜率是否相同，不用来决定哪一列可以出现。

## 估计

样本、缩尾、因变量、IMS、IMS_D、全部控制变量和 20% 切点与企业固定效应脚本相同。公司均值只在进入该次回归的观测上计算，包括年份哑变量的公司均值。估计是混合 OLS，标准误按公司聚类。组间斜率是组内斜率与该公司均值系数之和，标准误来自同一聚类稳健协方差矩阵的线性组合。

## 等价核对

Wooldridge 命题对应的企业 + 年份固定效应，是把因变量、协变量和年份哑变量一起做公司内去均值。CRE 的组内斜率与这个对照的绝对差小于 1e-6。只保留至少有两年观测的公司后，该对照与 `PanelOLS` 的个体加时间效应一致。

既有 `run_firm_fe_regression.fit` 已把年份哑变量与协变量一起做公司内去均值。CRE 组内斜率与既有脚本的绝对差小于 1e-6。

- IMS，全样本：CRE 组内 -0.2360，命题对照 -0.2360，绝对差 1.693e-15，既有脚本 -0.2360，与既有脚本绝对差 1.693e-15。
- IMS，T_i大于等于2：CRE 组内 -0.2360，命题对照 -0.2360，绝对差 6.495e-15，既有脚本 -0.2360，与既有脚本绝对差 6.495e-15。
- IMS_D，全样本：CRE 组内 -0.0971，命题对照 -0.0971，绝对差 9.853e-15，既有脚本 -0.0971，与既有脚本绝对差 9.853e-15。
- IMS_D，T_i大于等于2：CRE 组内 -0.0971，命题对照 -0.0971，绝对差 6.217e-15，既有脚本 -0.0971，与既有脚本绝对差 6.217e-15。

## 系数与归类

归类在看系数之前固定，显著性水平 5%。IMS 与 IMS_D 分开。判断两条斜率是否相同，用的是专长自身的公司均值系数，不是全部均值的联合检验。敏感性检验不改变归类。

- IMS：组内斜率 -0.2360（标准误 0.2299，p = 0.305）与组间斜率 -0.5627（标准误 0.2638，p = 0.033）同为负。专长自身的公司均值系数没有拒绝二者相等（p = 0.354）。方向与正文一致。组内斜率本身不显著，组间斜率单独看显著为负。组内最小可检测效应约 0.64，对基准效应的功效约 56%。
  IMS 的公司均值系数在 5% 水平不显著：看不出组内与组间是两条不同的斜率。
- IMS_D：组内斜率 -0.0971（标准误 0.0650，p = 0.135）与组间斜率 -0.1349（标准误 0.1042，p = 0.196）同为负。专长自身的公司均值系数没有拒绝二者相等（p = 0.762）。方向与正文一致。组内斜率本身不显著，组间斜率单独看也不显著。组内最小可检测效应约 0.18，对基准效应的功效约 60%。
  IMS_D 的公司均值系数在 5% 水平不显著：看不出组内与组间是两条不同的斜率。
