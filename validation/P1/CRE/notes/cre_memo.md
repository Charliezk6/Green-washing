# 相关随机效应：组内与组间

正文主规格仍是行业 + 年份固定效应。这里用 Wooldridge (2019) 的非平衡面板 Mundlak 装置，把组内斜率和组间斜率放在同一张表里。ξ = 0 的检验用来读这两条斜率是否相同，不用来决定哪一列可以出现。

## 估计

样本、缩尾、因变量、IMS、IMS_D、全部控制变量和 20% 切点与企业固定效应脚本相同。公司均值只在进入该次回归的观测上计算，包括年份哑变量的公司均值。估计是混合 OLS，标准误按公司聚类。组间斜率是组内斜率与该公司均值系数之和，标准误来自同一聚类稳健协方差矩阵的线性组合。

## 等价核对

Wooldridge 命题对应的企业 + 年份固定效应，是把因变量、协变量和年份哑变量一起做公司内去均值。CRE 的组内斜率与这个对照的绝对差小于 1e-6。只保留至少有两年观测的公司后，该对照与 `PanelOLS` 的个体加时间效应一致。

既有 `run_firm_fe_regression.fit` 只对公司内的因变量和协变量去均值，年份哑变量仍以水平值进入。在非平衡面板里，这不等于上面的企业 + 年份组内估计。IMS 相差约 0.005，IMS_D 相差约 0.003，来自定义不同，不是 CRE 没有对齐命题。下表和解读里的组内斜率用命题对照；既有脚本的系数另列，便于和原来的企业固定效应表对照。

- IMS，全样本：CRE 组内 -0.2360，命题对照 -0.2360，绝对差 1.693e-15，既有脚本 -0.2410，与既有脚本绝对差 0.0050。
- IMS，T_i大于等于2：CRE 组内 -0.2360，命题对照 -0.2360，绝对差 6.495e-15，既有脚本 -0.2404，与既有脚本绝对差 0.0044。
- IMS_D，全样本：CRE 组内 -0.0971，命题对照 -0.0971，绝对差 9.853e-15，既有脚本 -0.0999，与既有脚本绝对差 0.0028。
- IMS_D，T_i大于等于2：CRE 组内 -0.0971，命题对照 -0.0971，绝对差 6.217e-15，既有脚本 -0.0998，与既有脚本绝对差 0.0027。

## 系数与归类

归类在看系数之前固定，显著性水平 5%。IMS 与 IMS_D 分开。敏感性检验不改变归类。

- IMS：组内斜率 -0.2360（标准误 0.2299，p = 0.305）与组间斜率 -0.5627（标准误 0.2638，p = 0.033）同为负。全样本联合检验没有拒绝全部公司均值系数为零（p = 0.095），因此没有拒绝组内斜率与组间斜率相同。方向与正文一致。组内斜率本身不显著，组间斜率单独看显著为负。组内最小可检测效应约 0.64，对基准效应的功效约 56%。
  IMS 的公司均值系数在 5% 水平不显著：看不出组内与组间是两条不同的斜率。
- IMS_D：组内斜率 -0.0971（标准误 0.0650，p = 0.135）与组间斜率 -0.1349（标准误 0.1042，p = 0.196）同为负。全样本联合检验没有拒绝全部公司均值系数为零（p = 0.112），因此没有拒绝组内斜率与组间斜率相同。方向与正文一致。组内斜率本身不显著，组间斜率单独看也不显著。组内最小可检测效应约 0.18，对基准效应的功效约 60%。
  IMS_D 的公司均值系数在 5% 水平不显著：看不出组内与组间是两条不同的斜率。

## 主检验与敏感性

唯一主检验是全样本、公司聚类的联合 Wald，原假设为全部公司均值系数等于 0，含年份哑变量的公司均值。

- IMS，全样本联合Wald（主检验，全样本）：统计量 26.23，自由度 18，p = 0.0945，5% 水平不拒绝。列标准化条件数 7023.5。
- IMS，子集Wald（敏感性，全样本）：统计量 6.68，自由度 9，p = 0.6709，5% 水平不拒绝。列标准化条件数 7023.5。
- IMS，T_i大于等于2联合Wald（敏感性，T_i大于等于2）：统计量 29.46，自由度 18，p = 0.0430，5% 水平拒绝。列标准化条件数 6938.6。
- IMS，Chamberlain联合Wald（敏感性，全样本）：统计量 26.52，自由度 21，p = 0.1874，5% 水平不拒绝。列标准化条件数 7025.6。
- IMS_D，全样本联合Wald（主检验，全样本）：统计量 25.47，自由度 18，p = 0.1124，5% 水平不拒绝。列标准化条件数 7026.5。
- IMS_D，子集Wald（敏感性，全样本）：统计量 5.82，自由度 9，p = 0.7573，5% 水平不拒绝。列标准化条件数 7026.5。
- IMS_D，T_i大于等于2联合Wald（敏感性，T_i大于等于2）：统计量 28.51，自由度 18，p = 0.0547，5% 水平不拒绝。列标准化条件数 6941.6。
- IMS_D，Chamberlain联合Wald（敏感性，全样本）：统计量 28.95，自由度 21，p = 0.1153，5% 水平不拒绝。列标准化条件数 7026.7。

敏感性检验与全样本主检验的 5% 结论不同的，只有下面这些。句子仍按全样本主检验归类。

- IMS 的T_i大于等于2联合Wald p = 0.043，5% 水平拒绝，与全样本主检验不同。不改变归类。
- IMS_D：子集检验、T_i ≥ 2 和 Chamberlain 与全样本主检验的 5% 结论相同。

列标准化条件数约 7000，因为几乎不随时间变化的控制与其公司均值接近共线。子集检验去掉 Size、Lev、FirmAge、SOE、Big4、LnAuditFee 的均值约束后，p 值明显更大。主检验仍是全样本联合 Wald。

## 随机效应补充列

随机效应用 `linearmodels.RandomEffects`，公司聚类标准误，方程里不放公司均值。两列都报告：仅年份效应；年份效应加行业哑变量。该列仅在 ξ = 0 下一致。随机效应显著，不写成组内效应已经恢复。

- IMS，仅年份效应：-0.4690（0.1692），p = 0.0056***。
- IMS，年份效应加行业哑变量：-0.4557（0.1764），p = 0.0098***。
- IMS_D，仅年份效应：-0.1320（0.0547），p = 0.0158**。
- IMS_D，年份效应加行业哑变量：-0.1350（0.0565），p = 0.0170**。
