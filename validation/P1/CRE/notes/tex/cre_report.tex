\section{核心结论}

$IMS$ 与 $IMS\_D$ 的组内斜率和组间斜率都为负，方向与正文一致。两条斜率是否相同，看的是专长自身的公司均值系数：全样本 $p=0.354$ 与 $0.762$，5\% 水平都不拒绝。组内斜率不显著是功效问题：对正文基准效应的功效只有约 56\% 与 60\%，置信区间同时盖住 0 和基准点估计。补上常数项后，与正文对照的随机效应（年份加行业）为 $IMS$ $-0.3429$（标准误 $0.1766$，$p=0.052$）和 $IMS\_D$ $-0.1181$（标准误 $0.0563$，$p=0.036$）。前者只在 10\% 水平显著，后者在 5\% 水平显著。这两列只在全部公司均值系数为零时一致，不写成组内效应已经恢复。$IMS$ 在 $T_i\ge 2$ 上的整组协变量联合检验 $p=0.043$，那是协变量整体相关的敏感性，不是专长两条斜率是否相等；专长自身的均值系数在该子样本上仍不显著（$p=0.308$）。

\section{目的}

正文主回归（行业加年份固定效应）比较的是同一行业、同一年份里不同公司的漂绿差异。把这种差异拆开，可以问两个问题：
\begin{itemize}
\item \textbf{组内}：同一家公司，审计师行业专长升降时，它的漂绿是否随之变化？这只利用公司自身随时间的变动，等价于企业加年份固定效应。
\item \textbf{组间}：长期专长水平高的公司与长期专长水平低的公司相比，平均漂绿是否更低？这利用的是公司之间的持久差异。
\end{itemize}
相关随机效应（CRE）在混合回归中加入各变量的公司均值 $\bar x_i$，一次回归同时给出两条斜率：
\begin{equation}
y_{it}=x_{it}\beta_W+\bar x_i\xi+\varepsilon_{it},\qquad \beta_B=\beta_W+\xi_{\mathrm{core}}.
\end{equation}
$\beta_W$ 是组内斜率，$\beta_B$ 是组间斜率，$\xi_{\mathrm{core}}$ 是专长这一项的二者之差。专长的两条斜率是否相同，检验的是 $\xi_{\mathrm{core}}=0$。全部均值系数为零是另一件事：它说的是企业异质性是否与整组协变量相关，这时随机效应才与组内斜率估计同一个效应。计算细节可见附录。

\section{建议表述}

\begin{quote}
为考察审计师行业专长与漂绿的关系是否只反映公司间的持久差异，我们采用相关随机效应模型（Wooldridge, 2019）将效应分解为组内斜率与组间斜率。连续专长 $IMS$ 与二元专长 $IMS\_D$ 的两条斜率均为负，与主回归方向一致；专长自身的公司均值系数在 5\% 水平不拒绝两条斜率相等（$p=0.354$、$0.762$）。组内斜率在统计上不显著（$IMS$：$-0.2360$，标准误 $0.2299$；$IMS\_D$：$-0.0971$，标准误 $0.0650$），但其置信区间同时包含 0 与主回归点估计，对主回归效应的检验功效约为 56\% 与 60\%，反映的是公司内专长变动有限导致的精度不足。加上行业哑变量的随机效应中，$IMS$ 为 $-0.3429$（$p=0.052$），$IMS\_D$ 为 $-0.1181$（$p=0.036$）；该列仅在全部公司均值系数为零时一致，故仅作补充，不写成组内效应已经恢复。整组协变量的联合检验在只保留至少两年观测的公司时，$IMS$ 方程 $p=0.043$；这不等于专长的两条斜率被拒绝，专长自身的均值系数在该子样本上 $p=0.308$。
\end{quote}

\noindent 企业固定效应脚本现已改为双向组内估计，全控制系数为 $-0.2360$（标准误 $0.2298$，$p=0.304$）与 $-0.0971$（标准误 $0.0650$，$p=0.135$），与 CRE 组内斜率的绝对差小于 $10^{-6}$。原先表中的 $-0.2410$、$-0.0999$ 不再是现行输出。

\appendix
\section{附录}

\subsection{方法细节}

因变量为连续漂绿，核心变量为连续市场份额 $IMS$ 与 20\% 切点的 $IMS\_D$，两条方程分开估计。控制变量、1\%/99\% 缩尾和公司聚类标准误与全控制企业固定效应一致。$x_{it}$ 包括专长、全部控制变量和年份哑变量，$\bar x_i$ 为其在该公司观测年份上的均值；非平衡面板中年份哑变量的公司均值随在样年份变化，必须纳入。Wooldridge（2019）证明，此时 $\beta_W$ 与企业加年份的组内估计相同。

主检验为全样本专长自身公司均值系数的 $t$ 检验，原假设为该系数为零，即专长的组内斜率等于组间斜率，水平 5\%。联合 Wald 的原假设是全部公司均值系数（含年份哑变量均值）为零，只作为协变量整体相关的敏感性。另报：(i) $T_i\ge 2$ 上的专长均值 $t$ 检验；(ii) Chamberlain 形式下专长各年历史系数的联合检验；(iii) 子集 Wald，只约束专长及组内方差占比较高的控制之均值，不约束 Size、Lev、FirmAge、SOE、Big4、LnAuditFee。随机效应含常数项，分仅年份效应与年份效应加行业哑变量两种设定。

\subsection{样本}

全样本 15{,}381 个公司--年度、4{,}604 家公司，2021--2024 年，与企业固定效应样本相同。$T_i\ge 2$ 子样本 15{,}012 个观测、4{,}235 家公司。$IMS$ 的组内变异约占其总方差的 15\%。

\subsection{为什么不做 Hausman 预检验}

先做 Hausman 预检验、再据此选择固定效应或随机效应，会使随后检验的水平严重失真（Guggenberger, 2010, \textit{Journal of Econometrics}）；该检验对模型选择既不必要也不充分（Clark and Linzer, 2015, \textit{Political Science Research and Methods}）。Bell and Jones（2015）与 Bell, Fairbrother and Jones（2019）主张同时报告组内与组间斜率。Wooldridge（2019, \textit{Journal of Econometrics}）给出了非平衡面板下 CRE 与组内估计的等价性。因此本文同时报告全部估计，报告方式在看系数之前固定。

\subsection{事先固定的归类规则}

显著性水平 5\%，$IMS$ 与 $IMS\_D$ 分开归类；稳健性检验不作为改变归类的条件。
\begin{enumerate}
\item 组内不显著、组间显著为负、专长自身均值系数拒绝：效应主要来自公司间持久差异；若该系数显著为负，组间降幅可能含自选择，组内效应不作因果解释。
\item 组内与组间同为负、专长自身均值系数不拒绝：方向与正文一致，数据不拒绝两条斜率相同；组内不显著归为精度不足。
\item 其余组合：如实报告两条斜率、标准误与专长均值系数的 $p$ 值。
\end{enumerate}
结果：$IMS$（组内 $-0.2360$，组间 $-0.5627^{**}$，专长均值 $p=0.354$）与 $IMS\_D$（组内 $-0.0971$，组间 $-0.1349$，专长均值 $p=0.762$）均属第 2 类。

\subsection{实现说明}\label{app:impl}

\begin{enumerate}
\item 公司均值只在该次回归实际使用的观测上计算。参照年为 2021 年，方程含 2022--2024 三个年份哑变量及其公司均值。
\item 等价核对：把因变量、专长、控制和年份哑变量一起做公司内去均值，再做混合最小二乘。CRE 组内斜率与之绝对差小于 $10^{-14}$；在 $T_i\ge 2$ 子样本上该对照与 \texttt{PanelOLS} 的个体加时间效应一致。
\item 企业固定效应脚本现把年份哑变量与因变量、协变量一起做公司内去均值。全控制输出为 $-0.2360$（标准误 $0.2298$）与 $-0.0971$（标准误 $0.0650$），与 CRE 组内斜率的绝对差小于 $10^{-6}$。原先的 $-0.2410$ 与 $-0.0999$ 来自只去均值协变量、年份哑变量保持水平值，已不再是现行输出。
\item 列标准化后设计矩阵条件数约为 7{,}000，因为规模、上市年限、产权性质、四大和审计收费几乎不随时间变化，其水平值与公司均值近似共线。这个条件数只用于整组协变量的联合检验；子集检验去掉上述变量的均值约束。它不用于判断专长的两条斜率是否相等。
\item 星号按 1\%、5\%、10\% 标注，归类只用 5\%。20\% 切点保持不变，也未限定为专长状态发生过切换的公司。
\end{enumerate}
