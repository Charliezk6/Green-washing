# 企业固定效应稳健性说明

## 一、为什么要做这一步

正文主回归控制的是**行业**和**年份**，比较的是：同一行业、同一年份里，聘请高行业专长审计师的公司，漂绿是否更低。

这样做有一个潜在问题：有些公司本身就更规范、更少漂绿，同时也更可能聘请专长较强的事务所。若如此，主回归里看到的“专长抑制漂绿”，有一部分可能只是**不同类型公司之间的差异**，而不一定是专长本身带来的作用。

目前做的内容是：其他条件与正文完全相同，只把行业固定效应换成**企业固定效应**。也就是只看**同一家公司在不同年份之间**专长变化与漂绿变化的关系，从而进一步控制“这家公司自身情况”这类不随时间改变的特征。

---

## 二、具体怎么做

- 样本、因变量、解释变量、全部控制变量、缩尾方式和标准误设定，均与正文基准回归一致。
- 共同样本：**15,381** 个公司–年度观测，**4,604** 家公司，**4** 个会计年度，**47** 个行业。
- 每家公司平均 3.34 年、中位 4 年；仅 1 年观测的公司 369 家。
- 解释变量仍为连续行业专长（IMS）和二元行业专长（`IMS_D=1{IMS≥0.20}`）。
- 唯一区别：主回归用**行业 + 年份**固定效应；本检验用**企业 + 年份**固定效应（组内去均值）。
- 本轮不重跑估计，数字来自 `outputs/tables/firm_fe_vs_baseline_core.csv` 与 `outputs/diagnostics/`。

---

## 三、主要结果（全部控制变量）

| 核心变量 | 正文基准回归（行业+年份） | 本检验（企业+年份） |
| ----- | ------------------ | ---------------- |
| IMS   | −0.4829** (0.2362) | −0.2360 (0.2298) |
| IMS_D | −0.1434* (0.0794)  | −0.0971 (0.0650) |

N 均为 15,381。基准 IMS 的 p≈0.041，Firm FE 的 p≈0.304；IMS_D 从 p≈0.071 变为 p≈0.135。调整 R² 从约 0.022 降到约 0.004。

可以看到：

- 在正文设定下，连续专长与二元专长均显著为负。
- 换成企业固定效应后，系数仍为负，但均不再显著。
- 标准误几乎没有变大（IMS：0.236 → 0.230），变化主要来自**点估计大约腰斩**，不是推断公式突然变宽。

## 四、为什么 Firm FE 不显著（不是算错）

企业固定效应**可以做**，现有实现与 `PanelOLS`（个体+时间）的系数差在数值误差以内。不显著是识别来源问题。年份哑变量与因变量、协变量一起做了公司内去均值；非平衡面板里只去均值协变量、再把年份哑变量以水平值放回，不是双向组内估计。修正前全控制 IMS 为 −0.2410，与现在的 −0.2360 相差约 0.005。

1. **变异几乎全在组间。** IMS 组间方差约占 85%，组内只占 15%；组内 SD 仅 0.032。漂绿同样以组间为主（约 77%）。IMS 与漂绿的组间相关为 −0.065，组内相关只有 −0.013。
2. **二元专长高度粘滞。** 4,604 家公司中 4,300 家（93.4%）在四年内从不切换 `IMS_D`：始终为 0 的 4,170 家，始终为 1 的 130 家，有过切换的只有 304 家（6.6%）。只保留切换公司再估，IMS_D 为 −0.022 (0.071)，更不显著。
3. **短面板。** 只有约四年，同一公司内部可供识别的专长变动很少。Firm FE 问的是“同一公司内部专长变动是否还对应漂绿变动”，现有数据几乎回答不了。
4. **与文献一致。** 市场份额专长在客户/企业固定效应或匹配后效应减弱或消失，是 Minutti-Meza (2013, JAR) 的已知模式。国内行业专长论文的主表也多为行业+年份 FE；公司 FE 通常只作稳健性，并不要求比行业 FE 更负、更显著。

因此：事务所层面 IMS 的主规格应继续用**行业 + 年份 FE**。企业 FE 作为更严的组内检验如实披露即可，不宜升成主表，也不宜为了对齐显著性去改 20% 门槛或只保留切换公司。这一判断下面用功效计算写死；能在企业固定效应下站住的，是事先规定的合伙人层面相对专长，不在这张表里。

## 五、其他工作

1. **换一种常用面板估计方法重算**，与当前 demean 结果几乎相同，说明不是程序实现错误。
2. **拆开看变异来源**：专长与漂绿的差异主要来自公司与公司之间；公司内部相关很弱。
3. **二元专长很少变动**：约 93% 公司样本期内 0/1 状态不变；切换子样本结论仍接近零。
4. **连续 IMS 虽有组内波动**（约 92% 公司 IMS 数值并非完全不变），但波动幅度很小，不足以支撑精确的组内识别。

## 六、功效：这张表检测不到基准效应

全控制企业固定效应的 IMS 系数为 −0.236，标准误为 0.230。按这个标准误，双侧 5% 水平、80% 功效的最小可检测效应是 **0.64**。基准效应是 0.48，落在检测范围之外。用基准系数作为真实效应时，这张表的实际功效只有约 **56%**。

企业固定效应的 95% 置信区间是 **[−0.686, 0.214]**，包含基准点估计 −0.483。把两个估计的聚类得分协方差算进去之后，检验「企业固定效应系数等于基准系数」的 Wald p 值约为 **0.41**。所以这张表同时做不到两件事：不能拒绝零，也不能拒绝基准。写成「企业固定效应推翻了基准」不符合这组数字。

`PanelOLS` 把被吸收的企业哑变量计入自由度后，标准误从 0.230 升到 0.271，最小可检测效应升到 0.76，p 值约为 0.38。点估计与去均值结果相同。自由度修正让推断更宽，不是把结果修回显著的办法。

事先规定、并且全部报告的另外三个规格同样不显著：

| 规格 | IMS 系数 | 标准误 | p 值 |
| --- | ---: | ---: | ---: |
| 剔除组内几乎不变的控制（Size、Lev、FirmAge、SOE、Big4、LnAuditFee） | −0.271 | 0.232 | 0.24 |
| 企业固定效应 + 行业×年份固定效应 | −0.269 | 0.287 | 0.35 |
| 企业固定效应，处理变量改用 leave-one-out IMS | −0.187 | 0.223 | 0.40 |

数字见 `outputs/tables/firm_fe_power_and_mde.csv` 与 `outputs/diagnostics/firm_fe_spec_extensions.csv`。

## 七、效应在组间，组内不等于零假设被接受

Mundlak 分解把 IMS 拆成公司内离差和公司均值，放在同一条行业 + 年份固定效应回归里：

| 成分 | 系数 | 标准误 | p 值 |
| --- | ---: | ---: | ---: |
| IMS 组内 | −0.290 | 0.230 | 0.21 |
| IMS 组间 | −0.529 | 0.288 | 0.066 |
| 组内 = 组间的 Hausman 检验 |  |  | 0.52 |

组间成分接近基准，并且在 10% 水平显著。组内成分更小、不显著。两者的差异本身也不显著：短面板没有足够信息拒绝「组内效应和组间效应相同」。IMS_D 的组内系数是 −0.109（p = 0.096），组间是 −0.161（p = 0.17），Hausman p = 0.70。这里的组内系数不等于纯企业固定效应，因为控制变量没有同步拆开、行业固定效应也还在。

测量误差会让组内估计进一步向零收缩。下面的 −0.209 不是全样本企业固定效应 −0.236。它是同时有审计收费份额和资产平方根份额的子样本（15,279 个观测、4,580 家公司）上、把年份哑变量一并公司内去均值之后的 IMS 系数，标准误 0.231。审计收费份额和资产平方根份额与营业收入 IMS 的组内相关系数约为 0.75 和 0.81，对应的组内信度比 λ 仍约为 **0.53** 和 **0.58**。古典修正 β/λ 把这个子样本系数从 −0.209 调到约 −0.39 和 −0.36，标准误按同样比例放大到 0.43 和 0.40，仍然不显著。用另一口径做工具变量时，去均值方式没有改，一阶段 F 远大于 10，组内 IV 系数仍接近 0（收费份额工具变量 −0.043，资产份额工具变量 −0.069），都不显著。因此衰减可以解释系数变小，不能把企业固定效应修成一个显著结果。

详见 `outputs/tables/mundlak_decomposition.csv` 与 `outputs/tables/measurement_error_correction.csv`。合伙人层面的检验单独写在 [`partner_level_memo.md`](partner_level_memo.md)。
