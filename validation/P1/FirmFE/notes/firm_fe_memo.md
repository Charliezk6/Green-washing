# 企业固定效应稳健性说明

## 一、为什么要做这一步

正文主回归控制的是**行业**和**年份**，比较的是：同一行业、同一年份里，聘请高行业专长审计师的公司，漂绿是否更低。

这样做有一个潜在问题：有些公司本身就更规范、更少漂绿，同时也更可能聘请专长较强的事务所。若如此，主回归里看到的“专长抑制漂绿”，有一部分可能只是**不同类型公司之间的差异**，而不一定是专长本身带来的作用。

目前做的内容是：其他条件与正文完全相同，只把行业固定效应换成**企业固定效应**。也就是只看**同一家公司在不同年份之间**专长变化与漂绿变化的关系，从而进一步控制“这家公司自身情况”这类不随时间改变的特征。

---

## 二、具体怎么做

- 样本、因变量、解释变量、全部控制变量、缩尾方式和标准误设定，均与正文基准回归一致。
- 共同样本：**15,381** 个公司–年度观测，**4,604** 家公司，**4** 个会计年度，**47** 个行业。
- 每家公司平均 3.34 年、中位 4 年；仅 1 年观测的公司 369 家。
- 解释变量仍为连续行业专长（IMS）和二元行业专长（`IMS_D=1{IMS≥0.20}`）。
- 唯一区别：主回归用**行业 + 年份**固定效应；本检验用**企业 + 年份**固定效应（组内去均值）。
- 本轮不重跑估计，数字来自 `outputs/tables/firm_fe_vs_baseline_core.csv` 与 `outputs/diagnostics/`。

---

## 三、主要结果（全部控制变量）

| 核心变量 | 正文基准回归（行业+年份） | 本检验（企业+年份） |
| ----- | ------------------ | ---------------- |
| IMS   | −0.4829** (0.2362) | −0.2410 (0.2297) |
| IMS_D | −0.1434* (0.0794)  | −0.0999 (0.0648) |

N 均为 15,381。基准 IMS 的 p≈0.041，Firm FE 的 p≈0.294；IMS_D 从 p≈0.071 变为 p≈0.123。调整 R² 从约 0.022 降到约 0.004。

可以看到：

- 在正文设定下，连续专长与二元专长均显著为负。
- 换成企业固定效应后，系数仍为负，但均不再显著。
- 标准误几乎没有变大（IMS：0.236 → 0.230），变化主要来自**点估计大约腰斩**，不是推断公式突然变宽。

## 四、为什么 Firm FE 不显著（不是算错）

企业固定效应**可以做**，现有实现也已与 `PanelOLS`（个体+时间）交叉验证：IMS 系数差约 0.005，IMS_D 约 0.003。不显著是识别来源问题。

1. **变异几乎全在组间。** IMS 组间方差约占 85%，组内只占 15%；组内 SD 仅 0.032。漂绿同样以组间为主（约 77%）。IMS 与漂绿的组间相关为 −0.065，组内相关只有 −0.013。
2. **二元专长高度粘滞。** 4,604 家公司中 4,300 家（93.4%）在四年内从不切换 `IMS_D`：始终为 0 的 4,170 家，始终为 1 的 130 家，有过切换的只有 304 家（6.6%）。只保留切换公司再估，IMS_D 为 −0.031 (0.070)，更不显著。
3. **短面板。** 只有约四年，同一公司内部可供识别的专长变动很少。Firm FE 问的是“同一公司内部专长变动是否还对应漂绿变动”，现有数据几乎回答不了。
4. **与文献一致。** 市场份额专长在客户/企业固定效应或匹配后效应减弱或消失，是 Minutti-Meza (2013, JAR) 的已知模式。国内行业专长论文的主表也多为行业+年份 FE；公司 FE 通常只作稳健性，并不要求比行业 FE 更负、更显著。

因此：主规格应继续用**行业 + 年份 FE**。企业 FE 作为更严的组内检验如实披露即可，不宜升成主表，也不宜为了对齐显著性去改门槛或只保留切换公司。

## 五、其他工作

1. **换一种常用面板估计方法重算**，与当前 demean 结果几乎相同，说明不是程序实现错误。
2. **拆开看变异来源**：专长与漂绿的差异主要来自公司与公司之间；公司内部相关很弱。
3. **二元专长很少变动**：约 93% 公司样本期内 0/1 状态不变；切换子样本结论仍接近零。
4. **连续 IMS 虽有组内波动**（约 92% 公司 IMS 数值并非完全不变），但波动幅度很小，不足以支撑精确的组内识别。
