# 合伙人层面专长的企业固定效应

## 一、为什么换到这一层

事务所份额 IMS 的企业固定效应没有检验力：组内标准差只有 0.032，80% 功效下最小能检出的效应是 0.64，大于基准效应 0.48。Goodwin and Wu（2014, *Review of Accounting Studies*）的做法是把专长从事务所/分所下沉到签字合伙人。他们的理由是，事务所份额在客户固定效应里太嘈杂；行业知识主要在签字合伙人的人力资本上。

本样本里，四年内更换事务所的公司约占 32%，`IMS_D` 发生切换的公司只有 6.6%，但签字会计师组合发生过变化的公司约占 88%。合伙人层面至少有组内变动的原料。20% 的事务所切点不能直接用：合伙人–行业–年度份额的中位数只有 0.16%，第 90 百分位约 2.0%。阈值因此改成两个事先写定的相对规则，而不是 20%。

- `PIMS_D_leader`：该行业–年度份额最高的签字合伙人；并列最高都算。公司当年任一签字合伙人是领导者则取 1。这样的公司–年约占 1.1%。
- `PIMS_D_p90`：签字合伙人份额达到该行业–年度合伙人份额的第 90 百分位。这样的公司–年约占 13.2%。

连续变量用签字合伙人份额的最大值 `PIMS_max`（主口径）和平均值 `PIMS_mean`。leave-one-out 版本从分子和分母里都去掉本公司营收。同一客户的营收会计入每一位签字合伙人，所以行业内合伙人份额之和可以大于 1。没有合伙人身份证号，同名不同人会并在一起。构造见 `partner/scripts/build_partner_ims.py`，规则见 `partner/config/partner_ims_config.json`。

## 二、组内到底有多少信息

共同样本 15,380 个公司–年、4,604 家公司。

| 变量 | 组内标准差 | 组内有变动的公司占比 |
| --- | ---: | ---: |
| IMS | 0.032 | 92.0% |
| PIMS_max | 0.006 | 92.0% |
| PIMS_LOO_max | 0.005 | 35.5% |
| PIMS_D_leader | 0.036 | 0.6%（27 家） |
| PIMS_D_p90 | 0.142 | 8.8%（404 家） |

`PIMS_max` 的组内波动比 IMS 更小。多数合伙人在该行业的营收就是眼前这家客户，去掉本公司之后份额中位数变成 0。连续合伙人份额因此仍然很黏，而且很大一块是本公司自己的规模。领导者虚拟变量几乎不切换。90 分位虚拟变量的切换公司比 `IMS_D` 多（404 对 304），组内标准差也更大。

## 三、回归结果

全部控制变量，公司聚类。主对照表是 `outputs/tables/partner_vs_firm_specialization.csv`。

| 规格 | 变量 | 系数 | 标准误 | p 值 |
| --- | --- | ---: | ---: | ---: |
| 行业 + 年份 | IMS | −0.483 | 0.236 | 0.041 |
| 行业 + 年份 | PIMS_max | −3.081 | 0.882 | <0.001 |
| 企业 + 年份 | PIMS_max | −1.627 | 1.230 | 0.186 |
| 企业 + 年份，两者同时放入 | PIMS_max | −1.500 | 1.235 | 0.225 |
| 企业 + 年份，两者同时放入 | IMS | −0.204 | 0.231 | 0.378 |

行业 + 年份下，合伙人份额比事务所份额更显著。换成企业固定效应后，连续 `PIMS_max` 仍为负，但公司聚类下不显著。按事务所聚类时 p 值约为 0.072；受限 wild cluster bootstrap（Webb 六点权重，999 次，96 个事务所）的 p 值是 0.107。leave-one-out 的连续份额在企业固定效应下不显著（系数 −1.068，p = 0.43）。

两个二元规则不一样：

| 规格 | 变量 | 系数 | 标准误 | p 值 |
| --- | --- | ---: | ---: | ---: |
| 企业 + 年份，公司聚类 | PIMS_D_p90 | −0.108 | 0.052 | 0.036 |
| 企业 + 年份，事务所聚类 | PIMS_D_p90 | −0.108 | 0.044 | 0.015 |
| 企业 + 年份，wild bootstrap | PIMS_D_p90 | −0.108 |  | 0.035 |
| 企业 + 年份，同时放入 IMS_D | PIMS_D_p90 | −0.106 | 0.052 | 0.039 |
| 企业 + 年份，同时放入 IMS_D | IMS_D | −0.097 | 0.065 | 0.133 |
| 企业 + 年份，公司聚类 | PIMS_D_leader | −0.555 | 0.241 | 0.021 |
| 企业 + 年份，wild bootstrap | PIMS_D_leader | −0.555 |  | 0.127 |

`PIMS_D_p90` 在公司聚类、事务所聚类和 wild bootstrap 下都保持在 5% 水平。把事务所二元专长 `IMS_D` 同时放进企业固定效应后，90 分位系数几乎不变，`IMS_D` 不再显著。这是 Goodwin–Wu 的格局：更细的专长度量留下，事务所份额退出。

上表的企业固定效应仍是旧算法：只对公司内的因变量和协变量去均值，年份哑变量以水平值进入。事务所 IMS 的企业固定效应已经改成把年份哑变量一并去均值。两套口径因此不同。原表的 −0.108（p = 0.036）保留，不改写成新结果。

用与事务所 IMS 相同的双向组内估计重跑已报告的企业固定效应列，写在 `partner/outputs/tables/partner_fe_twoway_sensitivity.csv`，不覆盖原表：

| 规格 | 变量 | 原表系数 | 原表 p 值 | 双向组内系数 | 双向组内标准误 | 双向组内 p 值 |
| --- | --- | ---: | ---: | ---: | ---: | ---: |
| 企业 + 年份 | PIMS_max | −1.627 | 0.186 | −1.603 | 1.231 | 0.193 |
| 企业 + 年份，同时放入 IMS | PIMS_max | −1.500 | 0.225 | −1.479 | 1.237 | 0.232 |
| 企业 + 年份 | PIMS_D_p90 | −0.108 | 0.036 | −0.108 | 0.052 | 0.035 |
| 企业 + 年份，同时放入 IMS_D | PIMS_D_p90 | −0.106 | 0.039 | −0.107 | 0.052 | 0.038 |
| 企业 + 年份 | PIMS_D_leader | −0.555 | 0.021 | −0.552 | 0.240 | 0.022 |

`PIMS_D_p90` 在双向组内估计下仍为 −0.108（0.052），p = 0.035，5% 水平的结论与原表相同。

`PIMS_D_leader` 的传统标准误显著，但只有 27 家公司在样本期内切换，wild bootstrap p 值为 0.127。这个星号不能当作稳健结果。

## 四、换签字人事件

处理组是签字人组合发生变化，并且专长状态从 0 变为 1。对照组同样更换签字人，但换入的不是专长合伙人。规格是企业 + 年份固定效应。领导者定义下只有 7 家处理公司，事件研究里个别远期系数会因为观测太少而显得极显著，不采用。

90 分位定义下有 113 家处理公司、3,219 家对照公司。

| 规格 | 系数 | 标准误 | p 值 |
| --- | ---: | ---: | ---: |
| 企业 + 年份，Treat × Post | −0.258 | 0.102 | 0.011 |
| 加上全部控制变量 | −0.253 | 0.103 | 0.014 |
| 事件研究，相对时点 −2（省略 −1） | 0.197 | 0.110 | 0.072 |
| 事件研究，时点 0 | −0.225 | 0.107 | 0.034 |
| 事件研究，时点 +1 | −0.128 | 0.134 | 0.339 |
| 事件研究，时点 +2 | −0.425 | 0.178 | 0.017 |

Sun–Abraham 式的分队列当期效应按处理公司数加权后约为 −0.155。2022 队列接近 0（57 家，p = 0.86），2023 队列为 −0.10（25 家，p = 0.54），2024 队列为 −0.52（31 家，p = 0.026）。加权平均没有再做队列间的标准误。

时点 −2 的系数为正，并且在 10% 水平显著，平行趋势并不干净。事件研究可以和全样本企业固定效应对照着看，不能单独写成已经排除了换人选择。上表同样使用旧的企业固定效应算法。双向组内的 Treat × Post 写在 `partner/outputs/tables/partner_switch_did_twoway_sensitivity.csv`，不覆盖原表：90 分位、加上控制变量后为 −0.253（0.103），p = 0.014，与原表 −0.253（p = 0.014）一致。领导者定义下双向组内为 −0.613（0.386），p = 0.112，原表传统标准误显著的结论在这个敏感性里不再显著；该定义本来就只有 7 家处理公司，仍不作为稳健证据。

## 五、可以写进正文的句子，以及不该写的句子

可以写的是：事务所份额的企业固定效应功效不足，置信区间包含基准估计。把专长改到签字合伙人之后，行业–年度份额处于前 10% 的合伙人与更低的漂绿相关；这一关系在企业固定效应、事务所聚类和 wild cluster bootstrap 下仍显著，并且在同时控制事务所二元专长后仍然保留。换入这类合伙人的公司，相对换入非此类合伙人的公司，漂绿下降约 0.25，但事前趋势并不平坦。

不该写的是：连续合伙人份额的企业固定效应已经显著；行业领导者指标已经稳健；事件研究已经排除了自选择。连续份额和领导者指标都按原计划报告了，它们的组内证据弱于 90 分位指标。主回归仍然是行业 + 年份固定效应下的事务所 IMS。
