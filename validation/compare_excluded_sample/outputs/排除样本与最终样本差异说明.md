# 排除样本与最终样本的差异

排除组是连续漂绿缺失的 1,594 个公司—年，保留组是最终回归样本 15,381 个公司—年。
连续控制变量使用在保留组上计算的 1% 与 99% 缩尾边界，同一边界应用到排除组。IMS 不缩尾。
均值差等于排除组均值减去保留组均值。显著性来自该变量对排除组虚拟变量的回归，标准误按公司聚类。
排除组涉及 779 家公司，保留组涉及 4,604 家公司，其中 515 家公司在不同年份分别出现在两组。

## 公司特征

在 10% 水平上显著的变量如下。标准化均值差的绝对值达到 0.10 时，记为达到参照。

- IMS：排除组均值 0.0823，保留组均值 0.0698，排除组比保留组更高 0.0125（***，p = 0.0002）。标准化均值差为 0.151，达到 0.10。
- Size：排除组均值 22.8468，保留组均值 22.3249，排除组比保留组更高 0.5219（***，p < 0.0001）。标准化均值差为 0.368，达到 0.10。

- Growth：排除组均值 0.1607，保留组均值 0.0957，排除组比保留组更高 0.0649（***，p < 0.0001）。标准化均值差为 0.196，达到 0.10。该比较使用排除组中该变量非缺失的 1,465 条。
- ListingAge：排除组均值 7.6320，保留组均值 11.2589，排除组比保留组更低 3.6269（***，p < 0.0001）。标准化均值差为 -0.422，达到 0.10。
- SOE：排除组均值 0.2422，保留组均值 0.2768，排除组比保留组更低 0.0347（*，p = 0.0523）。标准化均值差为 -0.079，未达到 0.10。
- Dual：排除组均值 0.4134，保留组均值 0.3439，排除组比保留组更高 0.0695（***，p = 0.0003）。标准化均值差为 0.144，达到 0.10。该比较使用排除组中该变量非缺失的 1,565 条。
- BoardSize：排除组均值 2.2297，保留组均值 2.1129，排除组比保留组更高 0.1168（***，p < 0.0001）。标准化均值差为 0.517，达到 0.10。
- IndDirector：排除组均值 0.3770，保留组均值 0.3826，排除组比保留组更低 0.0056（**，p = 0.0129）。标准化均值差为 -0.092，未达到 0.10。
- Big4：排除组均值 0.1474，保留组均值 0.0555，排除组比保留组更高 0.0920（***，p < 0.0001）。标准化均值差为 0.308，达到 0.10。

- Tenure：排除组均值 7.1317，保留组均值 7.9131，排除组比保留组更低 0.7813（***，p = 0.0003）。标准化均值差为 -0.135，达到 0.10。
