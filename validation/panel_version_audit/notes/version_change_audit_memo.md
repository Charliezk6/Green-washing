# 面板版本差异审计备忘

日期：2026-09-10  
范围：只读对照 Version 1（`archive/Regression_reproduction`，共同样本 8,129）与 Version 2（`Regression`，共同样本 14,778）。**未修改** `Regression/data/input/`，**未改**论文，**未重跑** P1 稳健性。

判定标准：

- **有效**：同一公司—年字段一致，或差异可由文档化的样本扩张解释。
- **有意规格**：识别或变换选择（切点、缩尾、是否取对数），须单独报告。
- **无效**：编码或构造错误，不能当作样本结构变化写入论文。
- **可疑**：文档与代码冲突，或口径未在合并样本上统一。

## 1. 样本键：扩张有效，且完全嵌套

| 阶段 | N | 公司数 |
|------|---|--------|
| V1 输入面板 | 9,239 | 2,867 |
| V1 共同样本 | 8,129 | 2,669 |
| V2 合并输入 | 18,077 = 9,239 原面板 + 8,838 扩展 | 4,949 |

- V1 共同样本的 8,129 个公司—年**全部**出现在 V2 共同样本（`only_v1 = 0`）。

**分类：有效（样本扩张本身）。** DeepGreen 扩展把观测从 8,129 增至 14,778 是真实的键集合变化，不是计数错误。

重叠 8,129 上 `IMS`、`SOE`、`Dual`、`Big4`、`FirmAge`、`Greenwashing连续_基准` 与 V1 **完全一致**（相关 = 1，逐值相等）。原面板行是原样拷贝。

## 2. SOE 22.7% → 57.5%：无效编码

证据（`outputs/soe_audit_summary.csv`，`soe_recode_fill0.csv`）：

1. 扩展共同样本 6,649 行 **SOE 全部为 1**。
2. 这 6,649 行 `S0701b`（实际控制人姓名）也全部非空；`SOE == 1{S0701b 非空}` 在扩展行上成立率为 **100%**。
3. `build_combined_panel.py` 写的是 `SOE = 1 if S0701b else 0`，即用姓名非空当国企，不是产权性质。
4. 原面板在 `S0702b` 非缺失时，`SOE = 1` 当且仅当 `S0702b ∈ {1100, 2000, 2100, 2120}`，一致率 **100%**（5,749 行）。`S0702b` 缺失时原面板记 SOE = 0。
5. 全市场几乎都有控制人姓名：原面板 `S0701b` 非空比例也是 100%，因此姓名规则在原样本上也会把几乎所有公司打成 SOE=1；原面板之所以仍是 22.7%，是因为它**没有**用这条规则。

按原面板规则重编（只对比、未写回）：

| 范围 | 存盘 SOE | `S0702b` 四码、缺失当 0 |
|------|----------|-------------------------|
| V2 共同样本原面板部分 | 22.66% | 22.66%（完全复原） |
| V2 共同样本扩展部分 | **100%** | **34.17%** |
| V2 共同样本全体 | **57.46%（论文 57.5%）** | **27.84%** |

扩展样本按正确规则也只有约 34% 国企，略高于原 23%，**远远到不了 57.5%**。论文 “State-controlled firms account for 57.5 percent” 不能解释为扩样后国企更多。

嵌套回归诊断：在 V2 全样本上把 SOE 换成 `S0702b` 重编码后，因 `S0702b` 缺失，有效 N 从 14,778 降到 12,092，IMS 系数由 −0.543（p=0.023）变为 −0.371（p=0.145）。这不是正式结果，只说明错误的 SOE 可能影响推断。

**分类：无效。** 57.5% 是扩展行编码错误抬高的，不是可辩护的样本结构。

## 3. 标准化 ddof=0 → ddof=1：次要；真正的问题是 Y 未在合并样本上统一重算

重叠 8,129 的存盘 Y 与 V1 **逐值相同**。V2 没有改原样本的漂绿得分，只是把扩展行的 `Greenwashing连续` 拼进去。

在**合并样本**上按不同分组 / `ddof` 重算 z 分，再与存盘 Y 比较：

| 子样本 | 重算口径 | 与存盘相关 | RMSE |
|--------|----------|------------|------|
| 原面板共同样本 | 行业名称, ddof=0 | 0.950 | 0.417 |
| 原面板共同样本 | `ExpertiseIndustryCode`, ddof=1 | 0.947 | 0.428 |
| 扩展共同样本 | 行业基准分组, ddof=1 | **0.980** | 0.274 |
| 扩展共同样本 | `ExpertiseIndustryCode`, ddof=1 | 0.968 | 0.348 |
| 全体共同样本 | 行业基准分组, ddof=1 | 0.962 | 0.368 |

同一分组下 `ddof=0` 与 `ddof=1` 几乎不可区分（相关差约 0.0005）。**ddof 切换本身可视为有意、影响很小的修正。**

但存盘 Y 不是合并样本的行业—年度 z 分：

- 原 8,129 行仍是**原研究宇宙**里算出的 z 分；
- 扩展 6,649 行更接近 **DeepGreen 扩展宇宙**、`行业基准分组`、`ddof=1` 的 z 分；
- 回归把两套参照系下的分数当作同一因变量。

Y 的样本标准差约 1.34，原样本重算 RMSE 约 0.42，不是可忽略的噪声。

**分类：**

- `ddof=0 → 1`：**有意规格 / 影响很小**。
- 合并后面板混用两套行业—年度标准化：**无效混用（可疑程度已由 RMSE 坐实）**。

## 4. 控制变量与 IMS 切点

### 4.1 `IMS_D`：10% → 20%（有意规格，且会改结论）

V2 加载时用 `IMS >= 0.20` 重切二元专长，不沿用存盘 `IMS_D`。

| 样本 | `IMS≥0.10` 占比 | `IMS≥0.20` 占比 |
|------|-----------------|-----------------|
| V2 共同样本原部分 | 22.9%（与 V1 一致） | 4.9% |
| V2 共同样本扩展部分 | 27.2% | 6.9% |
| V2 共同样本全体 | 24.9% | **5.8%** |

重叠 8,129、V1 控制、V1 的 Y：

- `IMS_D≥0.10`：−0.113，p=0.031（\*\*）
- 只改 `IMS_D≥0.20`：−0.112，**p=0.300（不显著）**

切点从 10% 提到 20% 后，处理组过小，**在原样本上就会失去显著性**。这是识别定义，可以保留，但不能和扩样、SOE、Y 混在一起讲成“新样本复制了旧结论”。

**分类：有意规格。**

### 4.2 `FirmAgeLog` → `FirmAge`（有意规格 + 文档漂移）

重叠样本 `FirmAge` 与 V1 完全一致。V2 回归用原始上市年限，不再 `ln(1+FirmAge)`；二者相关约 0.93。重叠样本上改用 `FirmAge` 并 1%/99% 缩尾后，IMS 仍为 −0.862（\*\*\*），与 V1 的 −0.874（\*\*\*）接近。

[`Regression/regression README.md`](../../../Regression/regression%20README.md) 仍写财务控制含 `FirmAgeLog`，与代码和 `regression_config.json` 不一致。

**分类：有意规格；文档为可疑。**

### 4.3 缩尾（有意规格）

V2 在共同样本内对连续控制 1%/99% 缩尾；Y 与 IMS 不缩尾，与论文表述一致。多数变量每尾约 148 个观测被 clip。README 未写清缩尾，论文有写。

**分类：有意规格。**

### 4.4 Dual / Big4

共同样本中 `Dual ≡ (Y1001b==1)`、`Big4 ≡ (InternationalBig4==1)`，原面板与扩展均为 100% 一致。

**分类：有效。**
